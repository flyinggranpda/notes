## 阶段 1️⃣ 规则时代（1950s - 1980s）🔧

### 背景
NLP 刚诞生时，人们以为让计算机理解语言很简单——把语法规则写进去就行了。

### 里程碑事件
| 年份 | 事件 | 意义 |
|------|------|------|
| 1950 | 图灵测试提出 | 判断机器是否具有智能的标准 |
| 1954 | **Georgetown-IBM 实验** | 首次机器翻译演示（俄→英），翻译了 60 个句子 |
| 1966 | ELIZA 聊天程序 | 最早的聊天机器人（模拟心理治疗师） |

### 核心方法
- **手写语法规则**：由语言学家编写语法规则
  - 比如：主语 + 动词 + 宾语 → 人工定义模式
- **人工词典**：每个词的含义、词性提前标注好
- **模式匹配**：用固定模板匹配输入

### 为什么失败了？

```
输入："The car goes fast."
规则系统分析：
① car → 名词
② goes → 动词（第三人称单数）
③ fast → 副词

看似没问题，但换个句子就崩了：
"The fast car goes."  ← fast 在这里是形容词
或者：
"Time flies like an arrow."  ← 歧义！"flies" 是动词还是名词？
```

**三大致命问题：**
1. 🚫 **规则写不完** —— 语言有太多例外（中文尤其）
2. 🚫 **歧义无法解决** —— "我差点没上车" 到底上没上车？
3. 🚫 **无法扩展** —— 加一个新领域就要重写所有规则

## 阶段 2️⃣ 统计时代（1980s - 1990s）📊

### 核心思想转变
> 不再试图让计算机"理解"语言，而是让计算机**统计语言的规律**。

"只要语料够多，机器就能学会词的搭配规律。"

### 🔑 N-gram 模型（重点）

**定义**：基于前 N-1 个词预测第 N 个词的概率模型。

| 名称 | N 值 | 含义 | 例子（根据"我 爱"预测下一个） |
|------|------|------|----------------------------|
| **Unigram** | 1 | 只考虑词本身频率 | 出现最多的词 |
| **Bigram** | 2 | 看前 1 个词 | "爱"后面最可能跟什么？→ "你" |
| **Trigram** | 3 | 看前 2 个词 | "我 爱"后面最可能跟什么？→ "你" |

### 费曼理解 🍳

> N-gram 就像你在玩**词语接龙**：
> - **Unigram**：不管前面是什么，从所有词里随机抽一个（等于乱接）
> - **Bigram**：听了上一个词，想一个最常跟在它后面的词（"晚上" → "好"、"吃"→ "饭"）
> - **Trigram**：听了前两个词，想一个最常接在后面的（"今天 天气" → "真不错"）
>
> 但 N-gram 有上限——如果两个词隔了 5 个词的距离，它就完全看不到了。

### 🔑 Bag of Words（BoW，词袋模型）

**思想**：把文本看作一堆词的集合，**忽略词序**，只看词出现的情况。

```
句子1："我 爱 北京"
句子2："北京 我 爱"
→ BoW 表示完全相同！因为词袋不关心顺序
```

**表示方式**：
```
词汇表：{我, 爱, 北京, 天安门, 长城}
"我爱北京" → [1, 1, 1, 0, 0]  ← 词频向量
"北京长城" → [0, 0, 1, 0, 1]
```

**优点**：简单、直观、计算快
**缺点**：丢失了词序信息（"我打你"和"你打我"在 BoW 里一样！）

## 阶段 3️⃣ 机器学习时代（1990s - 2000s）🤖

### 背景
统计方法有一定效果，但需要更好的**分类算法**来处理 NLP 任务。

### 常用算法
| 算法 | 核心思想 | NLP 中的应用 |
|------|---------|-------------|
| **SVM**（支持向量机） | 在高维空间找最佳分类边界 | 文本分类、NER、情感分析 |
| **最大熵模型** | 在约束下选择最均匀的分布 | 词性标注、句法分析 |
| **CRF**（条件随机场） | 序列标注的"黄金标准" | NER、词性标注 |
| **HMM**（隐马尔可夫模型） | 基于状态转移的序列模型 | 词性标注、语音识别 |

### 机器学习在 NER 中的应用
```
传统 NER 流程：
原始文本 → 特征提取（大小写、词性、前后词）→ ML模型 → 实体标签
                                        ↑
                                   人工设计特征（特征工程）
```

**痛点**：特征工程依赖专家经验，非常耗时。

## 阶段 4️⃣ 深度学习时代（2010 - 2017）🧠

### 突破点
2010 年代初，深度学习开始在图像领域爆发，2012 年 CNN 在 ImageNet 大胜 → 研究者开始把深度学习方法用到 NLP。

### 关键技术

#### 📌 CNN + NLP
CNN（卷积神经网络）最初为图像设计，但也被应用到文本：
```
"这部电影 非常 好看"
     ↓  （词向量编码）
[0.2, 0.5, 0.1, ...]
[0.3, 0.1, 0.7, ...]
[0.6, 0.2, 0.3, ...]
     ↓  （卷积 + 池化）
文本分类结果 → 正面 ✅
```
- **优点**：可以提取局部词组特征（"非常好看"作为一个模式）
- **缺点**：对长距离依赖效果差

#### 📌 RNN（循环神经网络）—— 里程碑
**核心创新**：网络有"记忆"，能处理序列数据

```
RNN 展开图：
输出:     o1 → o2 → o3 → ...
          ↑    ↑    ↑
隐藏层:   h1 → h2 → h3 → ...  ← 记忆传递
          ↑    ↑    ↑
输入:     x1   x2   x3   ...
         "我" "爱" "你"
```

#### 📌 LSTM / GRU
- **LSTM**：在 RNN 基础上加了三道"门"，解决了梯度消失问题，可以记住更长的序列
- **GRU**：LSTM 的简化版，参数更少，效果差不多

#### 📌 Seq2Seq（序列到序列）
**核心思想**：编码器看完整输入 → 压缩成向量 → 解码器生成输出

```
输入（中文）:   "我 爱 你"
                  ↓
          编码器 RNN / LSTM
                  ↓
          语义向量（context vector）
                  ↓
          解码器 RNN / LSTM
                  ↓
输出（英文）:   "I  love  you"
```

**问题**：输入太长时，一个"语义向量"装不下所有信息 → 长句翻译效果差

## 阶段 5️⃣ Transformer 时代（2017 至今）⚡

### 2017 年：分水岭

> **论文**：Attention Is All You Need（Google，2017）
> **核心**：完全抛弃 RNN，只用 Attention 机制

### 从 RNN 到 Transformer 的思维转变

```
RNN 思路：    一个一个看词，记住前面看过的 ← 串行，慢
Transformer 思路：一眼看完所有词，看出哪些词之间关系密切 ← 并行，快
```

### 关键创新

| 创新点 | 做了什么 | 效果 |
|--------|---------|------|
| **Self-Attention** | 每个词跟句子中所有词计算相关性 | 捕捉长距离依赖 |
| **多头注意力** | 用多个不同角度计算注意力 | 更丰富的表示 |
| **位置编码** | 给每个词加上位置信息 | 让模型知道词序 |
| **并行计算** | 不再是 RNN 一步步走 | 训练速度大幅提升 |

### Transformer 架构图（简化版）

```
                  输出
                    ↑
                解码器层
         ┌────────────────────┐
         │  Masked Self-Attn   │
         │  交叉注意力(Encoder) │
         │  Feed Forward NN    │
         └────────────────────┘
                    ↑
                编码器层
         ┌────────────────────┐
         │  Self-Attention     │
         │  Feed Forward NN    │
         └────────────────────┘
                    ↑
                  输入
```

### 2018 年之后：两大分支

```
Transformer
    │
    ├──→ GPT 系列（自回归/单向）
    │    只用了 Transformer 的 Decoder
    │    预测下一个词
    │    GPT → GPT-2 → GPT-3 → GPT-4 → ...
    │
    └──→ BERT 系列（自编码/双向）
         只用了 Transformer 的 Encoder
         遮词预测（完形填空）
         BERT → RoBERTa → ALBERT → ...
```

## 📈 各模型/架构对比一览

| 方法 | 时期 | 核心思想 | 记忆口诀 | 能并行？ |
|------|------|---------|---------|---------|
| N-gram | 1980s | 前 N 个词预测下一个 | "就近看几个" | ✅ |
| BoW | 1980s | 词频统计，忽略顺序 | "把所有词倒进袋子" | ✅ |
| RNN | 2010s | 循环处理序列 | "串行记忆链" | ❌ |
| LSTM | 2010s | 三门控记忆流 | "带过滤器的记忆链" | ❌ |
| Seq2Seq | 2010s | 编码-解码 | "先看全再生成" | ❌ |
| Attention | 2015 | 关注重点位置 | "该看哪看哪" | ✅ |
| **Transformer** | **2017** | **全 Attention + 并行** | **"颠覆一切"** | ✅ |
| GPT | 2018+ | 单向语言模型 | "顺着编" | ✅ |
| BERT | 2018+ | 双向语言模型 | "完形填空" | ✅ |

## 🔑 演进本质：三条主线

纵观 70 年历史，NLP 技术的演进沿着三条主线：

### 主线 1：从手工到自动 🤖
```
人工写规则 → 统计概率 → 特征工程 → 自动学习特征 → 端到端
  (1950s)    (1980s)    (1990s)      (2010s)       (2017+)
```

### 主线 2：从串行到并行 ⚡
```
RNN（一步一歩走）→ CNN（局部并行）→ Transformer（全局并行）
```

### 主线 3：从单任务到大统一 💡
```
每个任务一个模型 → 预训练+微调 → 一个大模型做所有事
```

---

## 💡 核心 Takeaways

1. **NLP 的历史 = 不断减少人工干预**：规则 → 统计 → 机器学习 → 端到端深度学习
2. **N-gram** 是统计 NLP 的基石：Bigram = 看前一个词，Trigram = 看前两个词
3. **RNN → LSTM → Seq2Seq → Attention → Transformer** 是 NLP 深度学习的完整演进链
4. **2017 年 Transformer 是分水岭**：之前的架构（RNN/LSTM）被彻底取代
5. **GPT 走生成路线，BERT 走理解路线**，现在的大模型正在把两者融合

## ❓ 自测问题

<details>
<summary><b>Q1：规则翻译为什么失败了？</b></summary>

语言规则太多写不完，歧义难以处理，扩展性差。语言充满了例外和上下文依赖。
</details>

<details>
<summary><b>Q2：Bigram 和 Trigram 的区别是什么？</b></summary>

Bigram 根据前 1 个词预测当前词的概率；Trigram 根据前 2 个词预测当前词。Trigram 捕捉的上下文更多，但数据稀疏问题也更严重。
</details>

<details>
<summary><b>Q3：Bag of Words（词袋模型）最大的缺点是什么？</b></summary>

丢失词序信息。"我打你"和"你打我"在 BoW 中表示相同。
</details>

<details>
<summary><b>Q4：为什么说 2017 年是 NLP 的分水岭？</b></summary>

Google 发表 "Attention Is All You Need"，提出 Transformer 架构，完全抛弃 RNN，实现并行计算和全局注意力，从此 NLP 进入 Transformer 时代。
</details>

<details>
<summary><b>Q5：谁是"祖师爷"级别的创始概念？</b></summary>

N-gram 是最早的统计语言模型，算是 NLP 统计方法的"祖师爷"概念，直到今天在大模型中仍然能看到它的影子（预测下一个词）。
</details>
