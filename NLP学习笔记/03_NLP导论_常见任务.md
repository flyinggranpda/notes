## 🗺️ 全景概览：NLP 到底能做什么？

NLP 不是单一任务，而是**一整个任务家族**。我把它们分成三大类，方便记忆：

```
NLP 任务全家桶
│
├── 📖 理解类（从文本中提取信息）
│   ├── 文本分类（情感分析、垃圾邮件检测）
│   ├── 命名实体识别（NER）
│   ├── 词性标注（POS Tagging）
│   ├── 关系抽取
│   └── 阅读理解 / 问答
│
├── ✍️ 生成类（让机器写出文本）
│   ├── 机器翻译
│   ├── 文本摘要
│   ├── 对话生成（聊天机器人）
│   └── 故事/文章生成
│
└── 🔗 连接类（理解和生成结合）
    ├── 信息检索（搜索引擎）
    ├── 语音识别（ASR）
    └── 多模态任务（图文理解）
```

> 费曼说：**如果你能把这些任务讲给非技术朋友听，并且他们能理解 NLP 能干什么，你就掌握了。** 下面我逐个用大白话讲。

## 1️⃣ 文本分类（Text Classification） 🔵 最基础

**定义**：给定一段文字，判断它属于哪个类别。

### 常见应用

| 任务 | 输入 | 输出 | 生活类比 |
|------|------|------|---------|
| 情感分析 | "这产品太烂了" | 负面 ❌ | 自动判断顾客满不满意 |
| 垃圾邮件检测 | "点击领取百万大奖" | 垃圾邮件 🗑️ | 邮件过滤器 |
| 主题分类 | "股市今日大涨" | 财经 📊 | 自动打标签 |
| 意图识别 | "帮我订张机票" | 预订意图 | 客服机器人懂你要什么 |

### 费曼理解

> 就像你给朋友看一条微博，朋友说"这是在吐槽"—— 文本分类就是让机器学会这个判断能力。

### 常见模型方法

```
传统方法：朴素贝叶斯、SVM
深度学习：TextCNN、LSTM
当前主流：BERT 做分类（[CLS] token 接一个分类头）
大模型时代：直接 Prompt "这句话的情感是正面还是负面？"
```

## 2️⃣ 命名实体识别（NER）🟡 信息提取核心

**定义**：从文本中识别出**有特定意义的实体**（人名、地名、机构名、时间、金额等）。

### 例子

```
输入："小明昨天去了北京大学，花了200块钱买了本书。"

输出：
[小明]  👉 人名 (PER)
[昨天]  👉 时间 (TIME)
[北京大学] 👉 机构 (ORG)
[200块]  👉 金额 (MONEY)
```

### 🏷️ BIO 标注体系（字幕重点内容！）

BIO 是 NER 中最常用的标注方式，理解它对理解序列标注任务很关键：

| 标签 | 全称 | 含义 | 例子（"小明在北京大学读书"） |
|------|------|------|---------------------------|
| **B-PER** | Begin-Person | 实体的**开始**（人名） | 小 |
| **I-PER** | Inside-Person | 实体**内部**（人名） | 明 |
| **B-ORG** | Begin-Organization | 实体的**开始**（机构） | 北 |
| **I-ORG** | Inside-Organization | 实体**内部** | 京 大 学 |
| **O** | Outside | 不是实体 | 在 / 读 / 书 |

**举个例子可视化：**

```
文 字： 小  明  在  北  京  大  学  读  书
BIO：  B  I   O   B   I   I   I   O   O
       PER PER    ORG ORG ORG ORG
```

> **费曼理解**：BIO 就像给每个字贴标签 —— B 表示"实体开始了"，I 表示"还在实体里"，O 表示"跟实体没关系"。就像在文章里用荧光笔标记重点，B 是下笔那一点，I 是划过去的轨迹，O 是没划到的部分。

### 为什么要用 BIO？

因为实体可能包含多个字/词，需要标记**边界**。比如：

- "北京大学" 是 4 个字的机构名
- 如果只标"是/否实体"，无法区分"北京"（城市）和"北京大学"（机构）的范围

### NER 的应用场景
- 信息抽取（从新闻中提取人物、事件）
- 知识图谱构建
- 医疗文本（提取疾病、药物、症状）
- 金融文本（提取公司名、人名、金额）

## 3️⃣ 词性标注（POS Tagging）🟢 最经典

**定义**：给句子里的每个词标上词性（名词、动词、形容词……）。

```
输入："我 爱 自 然 语 言 处 理"
输出： 代 动 名 名 名 名 名
      词 词 词 词 词 词 词
```

**作用**：是很多下游任务（如句法分析）的基础。

---

## 4️⃣ 机器翻译（Machine Translation）🔴 最知名

**定义**：把一种语言的文本自动翻译成另一种语言。

### 技术演变

| 阶段 | 代表 | 特点 |
|------|------|------|
| 规则翻译 | 1980s | 人工编写语法规则 → 不灵活 |
| 统计翻译 | 1990s-2000s | 基于概率统计 → 效果一般 |
| 神经翻译 | 2015+（Seq2Seq + Attention） | 效果大幅提升 |
| 大模型翻译 | 2022+ | GPT 等直接翻译，不用专门模型 |

### 费曼理解
> 机器翻译就像一个人同时精通两门语言，读一句英文，在脑子里理解意思，再用中文重新表达出来。

---

## 5️⃣ 文本摘要（Text Summarization）

**定义**：把长文本压缩成简短的摘要，保留核心信息。

两种方式：
| 方式 | 做法 | 类比 |
|------|------|------|
| **抽取式** | 从原文里挑出最重要的句子组合 | 用荧光笔划重点 |
| **生成式** | 理解原文后用新句子重写 | 读完书后用自己的话写摘要 |

---

## 6️⃣ 问答系统（Question Answering）

**定义**：给定问题和上下文，给出答案。

两种类型：
- **抽取式 QA**：从给定的文章中找答案片段（如 BERT 的 SQuAD 任务）
- **生成式 QA**：不局限于给定文本，模型自己生成答案（如 ChatGPT）

---

## 7️⃣ 文本生成（Text Generation）

**核心**：给定一段开头或提示（Prompt），让模型续写。

从简单到复杂：
```
字符级生成 → 词级生成 → 句子级生成 → 篇章级生成
  "我爱"       "我爱北京"    "我爱北京天安门"    一篇完整的文章
```

大模型时代，我们已经可以做到：
- 写邮件
- 写代码
- 写诗
- 写故事
- 角色对话

---

## 8️⃣ 关系抽取（Relation Extraction）

**定义**：从文本中识别实体之间的语义关系。

```
输入："苹果公司在1976年由乔布斯创立"
输出：
  实体1     关系       实体2
  ┌─────┐  ┌──────┐  ┌──────┐
  │苹果公司│ ←创立于→ │ 1976年 │
  │苹果公司│ ←创始人→ │ 乔布斯 │
  └─────┘          └──────┘
```

**用途**：构建知识图谱（如 Google Knowledge Graph）

## 🆚 任务难度对比

| 任务 | 难度 | 对初学者的友好度 | 是否已被 LLM 基本解决 |
|------|------|-----------------|---------------------|
| 文本分类 | ⭐⭐ | ✅ 最简单入门 | ✅ |
| NER | ⭐⭐⭐ | ✅ 练习序列标注 | ✅ |
| 词性标注 | ⭐⭐ | ✅ | ✅ |
| 机器翻译 | ⭐⭐⭐⭐ | ❌ | ✅（GPT 级） |
| 文本摘要 | ⭐⭐⭐⭐ | ❌ | ✅（GPT 级） |
| 问答系统 | ⭐⭐⭐ | ✅ | ✅（GPT 级） |
| 文本生成 | ⭐⭐⭐⭐ | ❌ | ✅（GPT 级） |

> 🔑 **关键理解**：在大模型出现之前，每个任务都需要单独训练一个模型，任务之间的技术差异很大。**有了大模型之后，一个模型能搞定所有任务**，只是通过不同的 Prompt 来切换。这是 NLP 领域最革命性的变化！

---

## 💡 核心 Takeaways

1. **NLP 任务分三类**：理解类（提取信息）、生成类（创造文本）、连接类（两者结合）
2. **NER 中的 BIO 标注** 是最经典的序列标注方法——B=开始，I=内部，O=外部
3. 传统 NLP: **每个任务一个模型** → 现在 NLP: **一个大模型做所有任务**
4. 初学者建议从**文本分类**入手最简单，然后理解 NER 的序列标注思想
5. **Prompt（提示词）** 已经成为调用 NLP 能力的主要方式

## ❓ 自测问题

<details>
<summary><b>Q1：BIO 标注中 B、I、O 分别代表什么？</b></summary>

B = Begin（实体开始位置），I = Inside（实体内部），O = Outside（非实体）。
</details>

<details>
<summary><b>Q2：命名实体识别（NER）是做什么的？</b></summary>

从文本中识别出人名、地名、机构名、时间、金额等有特定意义的实体。
</details>

<details>
<summary><b>Q3：抽取式摘要和生成式摘要的区别？</b></summary>

抽取式是从原文直接挑选重要句子组合；生成式是理解原文后用自己的话重写。生成式更难但质量更高。
</details>

<details>
<summary><b>Q4：大模型出现前后，NLP 任务的做法有什么不同？</b></summary>

之前：每个任务（分类、NER、翻译）要单独训练专用模型。之后：一个通用大模型通过不同 Prompt 完成所有任务，无需单独训练。
</details>
