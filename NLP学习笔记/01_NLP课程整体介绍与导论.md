## 🧠 一句话说清 NLP

**NLP（Natural Language Processing，自然语言处理）** 就是让计算机能「听懂人话」—— 不只是把文字当成字符串处理，而是理解其中的**意图、情感、语义**，然后做出有价值的回应。

> 费曼说：如果你不能简单地解释它，你就没有真正理解它。  
> 下面我用一个类比👇

### 🍳 厨房类比

| 层次 | 人怎么做 | NLP 怎么做 |
|------|----------|-----------|
| 看菜名 | 知道是"番茄炒蛋" | 分词、识别实体 |
| 读菜谱 | 理解"少许盐"是多少 | 语义理解、消歧义 |
| 按步骤做 | 先炒蛋再放番茄 | 序列建模、生成文本 |
| 尝味道调整 | 咸了加点糖 | 反馈优化、微调 |

## 🧭 课程核心知识点

### 1️⃣ NLP 是什么

- **定义**：让计算机理解、生成、处理自然语言文本/语音
- **难度**：比图像处理更难 —— 语言充满歧义、上下文依赖、文化隐喻
- **重要性**：AI 从「能看」（CV）到「能听会说」（NLP）的关键跨越

### 2️⃣ 关键技术演进脉络（🚩 重点）

```
早期规则系统 ─→ 统计方法 ─→ 深度学习 ─→ 预训练大模型
   1950s         1990s       2010s        2018~
```

关键里程碑：

| 技术 | 核心思想 | 一句话记忆法 |
|------|---------|-------------|
| **CNN** | 卷积提取局部特征 | "看局部，拼全局" |
| **RNN** | 循环处理序列 | "有记忆，但健忘"（长距离会忘） |
| **LSTM** | 三门机制控制记忆流 | "装了个开关，该记记该忘忘" |
| **GRU** | LSTM 简化版 | "少个门，效果差不多" |
| **Seq2Seq** | 编码器-解码器框架 | "先理解再表达" |
| **Attention** | 关注重点部分 | "不再死记硬背，会查资料了" |
| **Transformer** | 完全抛弃 RNN，只用 Attention | "并行 + 全局关注" |
| **GPT** | 单向语言模型，生成式 | "顺着往下写" |
| **BERT** | 双向语言模型，理解式 | "左右逢源" |

### 3️⃣ 各阶段通俗解释

#### 🟢 RNN 时代（Recurrent Neural Network）
- **核心**：把上一个时刻的输出传给下一个时刻，形成"记忆链"
- **痛点**：链子太长就断了（梯度消失）—— 记不住太久之前的信息
- **类比**：一个人传悄悄话，传到最后全变样了

#### 🟢 LSTM / GRU（长短期记忆）
- **LSTM**：在 RNN 上加了三道"门"（输入门、遗忘门、输出门），控制什么该记、什么该忘
- **GRU**：把三道门简化成两道（重置门、更新门），效果差不多但参数更少
- **类比**：一个有筛选能力的笔记本 —— 重要的写下来，不重要的划掉

#### 🟢 Seq2Seq（Sequence to Sequence）
- **核心**：一个编码器把输入压成「语义向量」，一个解码器从这个向量生成输出
- **应用**：机器翻译、文本摘要
- **痛点**：输入太长，语义向量"装不下" —— 信息会丢失

#### 🟡 Attention 机制（划时代 💡）
- **核心**：生成每一步输出时，回头看输入的所有位置，挑重点关注
- **效果**：解决了长序列信息丢失问题
- **类比**：翻译时不是死记整句话，而是一边翻一边看原文的对应位置

#### 🔴 Transformer（革命性 🚀）
- **核心创新**：完全抛弃 RNN，**只用 Attention 机制** + 并行计算
- **Self-Attention**：每个词看句子里的所有词，判断相关性
- **优势**：
  - ✅ 可并行（不像 RNN 必须一步步走）
  - ✅ 解决长距离依赖
  - ✅ 训练效率大幅提升
- **结构**：Encoder（编码器）+ Decoder（解码器）

#### 🔴 GPT vs BERT（预训练时代两巨头）

| 对比维度 | GPT | BERT |
|---------|-----|------|
| 方向 | 单向（左→右） | 双向（左右看全身） |
| 擅长 | **生成**（写文章、对话） | **理解**（分类、情感分析、QA） |
| 训练方式 | 预测下一个词 | 随机遮词，猜被遮的词 |
| 全称 | Generative Pre-trained Transformer | Bidirectional Encoder Representations from Transformers |
| 记忆口诀 | "顺着往下编" | "完形填空高手" |

## 🔑 核心 Takeaways

1. NLP = 让计算机理解并生成人类语言
2. 技术演进：RNN → LSTM → Seq2Seq → **Attention** → **Transformer** （这是完整链条）
3. Transformer 是分水岭 —— 之前 RNN 称霸，之后 Attention 为王
4. GPT 系列 做生成，BERT 系列 做理解，现在的趋势是合二为一
5. 从"规则"到"统计"到"深度学习"到"预训练大模型"：数据量和模型参数指数增长

## ❓ 自测问题（读完先回忆，再看答案）

<details>
<summary><b>Q1：为什么 RNN 处理长文本效果不好？</b></summary>

→ 梯度消失问题。文本越长，反向传播时梯度连乘越来越小，前面的词就"学不到了"。
</details>

<details>
<summary><b>Q2：Transformer 相比 RNN 最大的改进是什么？</b></summary>

→ 两大改进：① 用 Self-Attention **替代循环**，可以**并行计算**；② 每个位置直接关注所有位置，解决长距离依赖。
</details>

<details>
<summary><b>Q3：GPT 和 BERT 的主要区别？</b></summary>

→ GPT 是**单向**语言模型（从左到右预测下一个词），适合生成任务；BERT 是**双向**（遮住一些词让模型猜），适合理解任务。简单记：GPT"写"，BERT"读"。
</details>

<details>
<summary><b>Q4：Attention 机制的核心思想是什么？</b></summary>

→ 生成输出时，不只看编码器的最后一个输出，而是看**所有输入位置的加权求和**，权重表示当前步对输入各位置的"关注程度"。
</details>
