# 标注数据很少，如何扩增训练数据的数量？

## 1. 课程元信息

- **主题**：小样本场景下的数据扩增策略 — 从传统数据增强到主动学习
- **前置知识**：数据标注、迁移学习、半监督学习、正则化
- **核心目标**：掌握三大数据扩增方向（数据增强、迁移学习、半监督/主动学习）

---

## 2. 核心概念图谱

| 术语 | 英文 | 通俗解释 |
|------|------|---------|
| 数据增强 | Data Augmentation | 对现有数据进行变换，生成语义不变的新样本 |
| 迁移学习 | Transfer Learning | 用预训练模型的通用特征适配小数据集 |
| 半监督学习 | Semi-supervised Learning | 少量标注数据 + 大量未标注数据联合训练 |
| 伪标签 | Pseudo Labeling | 用模型对未标注数据预测，把高置信度结果当标签 |
| 主动学习 | Active Learning | 筛选对模型提升最大的样本让人类标注 |
| 回译 | Back Translation | 文本 A→B→A，利用翻译的差异生成新文本 |

---

## 3. 技术原理 / 流程拆解

### 3.1 三大扩增方向

```
有限标注数据
    │
    ├── 方向一：对原始数据做变换（数据增强）
    │   ├── 图像：旋转/翻转/裁剪/加噪声/色彩抖动
    │   ├── 文本：同义词替换/回译/掩码填充
    │   └── 音频：音调扰动/频谱变化
    │
    ├── 方向二：借助预训练模型（迁移学习）
    │   ├── 冻结 + 微调（LoRA/PEFT）
    │   └── 领域适配（选相似领域预训练）
    │
    └── 方向三：利用未标注数据（半监督/主动学习）
        ├── 伪标签：模型预测 → 高置信度当标签
        └── 主动学习：选最不确定的样本让人标注
```

### 3.2 文本数据增强详解

| 方法 | 做法 | 效果 |
|------|------|------|
| 同义词替换 | 用工具（如 WordNet）替换为同义词 | 简单有效 |
| 回译 | 中文→英文→中文，利用翻译差异生成新文本 | **效果很好且简单** |
| 掩码填充 | 类似 MLM，掩盖部分词让模型预测替换 | 类似图像加噪声 |
| 句子结构变换 | 主动/被动语态转换，句式重构 | 适用性有限 |

### 3.3 主动学习的流程

```
Step 1: 用少量标注数据训练初始模型 M
Step 2: 用 M 对未标注数据做预测
Step 3: 筛选"最不确定"的样本
        ├── 不确定性采样（方差大/熵高）
        └── 多样性采样（聚类后选代表）
Step 4: 让人工标注筛选出的样本
Step 5: 加入训练集，重复迭代
```

**关键点**：不确定性最高的样本 = 对模型提升最大的样本。确定性能 100% 的样本没有训练价值。

---

## 4. 避坑指南

| 注意点 | 说明 |
|--------|------|
| 回译虽好但要注意语义偏移 | 多轮翻译可能改变原意 |
| 图像噪声要适度 | 噪声过大会让模型学不到有效特征 |
| 伪标签有错误累积风险 | 只取高置信度样本，且适用封闭式问题（如选择题） |
| 主动学习算法尚不成熟 | 当前效果有限，但未来潜力大 |
| 领域迁移要选相关性高的领域 | 医疗+法律（都重条文）比医疗+娱乐好 |

---

## 5. 本节课思维导图

- 数据扩增三大方向
  - 数据增强（原始数据变换）
    - 图像：旋转/裁剪/噪声/色彩
    - 文本：同义词替换/回译/掩码填充
    - 音频：音调扰动
  - 迁移学习（借助预训练模型）
    - 冻结 + 微调（LoRA/PEFT）
    - 选择相似领域做领域适配
  - 半监督 + 主动学习（利用未标注数据）
    - 伪标签（高置信度样本）
    - 主动学习（不确定性采样 + 多样性采样）
