# 正则化约束（Regularization）

## 1. 课程元信息

- **主题**：机器学习/深度学习中的正则化约束 — L1、L2、Elastic Net
- **前置知识**：过拟合、损失函数、参数优化
- **核心目标**：理解正则化的本质（给模型戴紧箍咒），以及三种主流正则化的区别

---

## 2. 核心概念图谱

| 术语 | 英文 | 通俗解释 |
|------|------|---------|
| 正则化 | Regularization | 对模型参数施加限制，防止过拟合的技术 |
| 过拟合 | Overfitting | 模型记住了训练数据的噪声，泛化能力差 |
| 泛化能力 | Generalization | 模型在新数据上的表现能力 |
| L2 正则化 | L2 Regularization (Ridge) | 惩罚参数平方和，让参数趋近于 0 但不为 0 |
| L1 正则化 | L1 Regularization (Lasso) | 惩罚参数绝对值，让部分参数变为 0（稀疏化） |
| Elastic Net | Elastic Net | L1 + L2 的组合，取两者优点 |
| 超球体 | Hypersphere | L2 在 n 维空间中的约束形状（球形） |
| 超立方体 | Hypercube | L1 在 n 维空间中的约束形状（菱形/多面体） |

---

## 3. 技术原理 / 流程拆解

### 3.1 正则化的核心公式

```
原始损失函数:            min L(θ)
加入正则化后:            min L(θ) + λ·R(θ)

L(θ) = 数据损失（如交叉熵）
R(θ) = 正则化项（对参数的约束）
λ   = 正则化强度（越大，约束越强）
```

**本质**：给模型戴上"紧箍咒"，不让参数肆意生长。

### 3.2 三种正则化方法

#### L2 正则化（Ridge）

```
R(θ) = ‖θ‖₂² = θ₁² + θ₂² + ... + θᵢ²

约束形状：超球体（二维=圆形，三维=球体）
效果：让参数趋近于更小、更平滑的值，但不会让参数为 0
```

**几何意义**：将所有参数限制在一个以原点为中心的球体内，超过球体的参数被"拉回来"。

#### L1 正则化（Lasso）

```
R(θ) = ‖θ‖₁ = |θ₁| + |θ₂| + ... + |θᵢ|

约束形状：超立方体（二维=菱形，三维=八面体）
效果：让部分参数变为 0，产生稀疏性
```

**为什么 L1 会产生稀疏性？**
```
L1 的约束形状有"棱角"，损失函数的等值线更容易与棱角相交
一旦在棱角处相交 → 某个维度的参数 = 0 → 特征被剔除

二维示例：
  菱形有 4 个角 → 每个角对应一个坐标轴上的参数为 0
  三维有 8 个角 → 更多参数可能变为 0
  n 维有 2ⁿ 个角 → 高维下大量参数稀疏化
```

#### Elastic Net（弹性网络）

```
R(θ) = α·‖θ‖₁ + (1-α)·‖θ‖₂²

α = 0   → 纯 L2 正则化
α = 1   → 纯 L1 正则化
0<α<1  → L1 + L2 混合
```

**结合了 L1 的稀疏性和 L2 的稳定性**，适用于特征高度相关的场景。

### 3.3 正则化的作用总结

| 作用 | 说明 |
|------|------|
| **防止过拟合** | 限制参数范围，避免模型学习噪声 |
| **参数平滑** | 让参数值更小，减少对输入的敏感度 |
| **特征选择（L1）** | 剔除不重要的特征，只保留关键特征 |
| **削弱噪声（L2）** | 让噪声特征的权重趋近于 0 |
| **缓解梯度爆炸** | 将大参数拉回合理范围，间接防止梯度在深层网络中爆炸 |

## 4. 避坑指南

| 注意点 | 说明 |
|--------|------|
| λ 太大 → 欠拟合 | 约束过强，模型学不到东西 |
| λ 太小 → 正则化失效 | 约束不足，仍会过拟合 |
| L1 不适合特征数极少的情况 | 稀疏化可能把有用特征也删掉了 |
| Elastic Net 不适合极端数据 | 某些极端场景下效果不如单独使用 L1 或 L2 |

---

## 5. 对比与思考

### 5.1 L1 vs L2

| 对比 | L1 正则化 | L2 正则化 |
|------|-----------|-----------|
| 公式 | Σ\|θᵢ\| | Σθᵢ² |
| 约束形状 | 超立方体（棱角多） | 超球体（圆滑） |
| 参数效果 | 让部分参数 = 0（稀疏化） | 让参数趋近但 ≠ 0 |
| 特征选择 | ✅ 可剔除无关特征 | ❌ 不剔除特征 |
| 适用场景 | 特征多，需要特征选择 | 特征少，需要参数平滑 |

### 5.2 过拟合的判定

面试必答：
> **Train Loss 很低，Validation Loss 在上升** → 过拟合了

## 6. 本节课思维导图

- 正则化约束
  - 定义：对参数施加限制，防止过拟合
  - 公式：min L(θ) + λ·R(θ)
  - 三种正则化
    - L2（Ridge）：平方和 → 球体 → 参数平滑
    - L1（Lasso）：绝对值 → 菱形/多面体 → 稀疏化
    - Elastic Net：L1+L2 混合 → 兼顾稀疏性和稳定性
  - 作用
    - 防止过拟合（核心）
    - 参数平滑
    - 特征选择（L1）
    - 削弱噪声（L2）
  - 过拟合判定：Train Loss ↓ + Val Loss ↑
