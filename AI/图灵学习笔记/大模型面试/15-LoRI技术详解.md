# LoRI 技术详解

## 1. 课程元信息

- **主题**：LoRI（LoRA 的进一步优化）— 冻结 A + 稀疏化 B
- **前置知识**：LoRA（低秩分解）、PEFT 概念
- **核心目标**：理解 LoRI 相比 LoRA 的核心改进点，以及为什么它在多任务场景下更优

---

## 2. 核心概念图谱

| 术语 | 英文 | 通俗解释 |
|------|------|---------|
| LoRI | Low-Rank with frozen A and sparse B | 冻结随机矩阵 A，仅训练并稀疏化矩阵 B |
| 随机投影 | Random Projection | 用随机初始化的固定矩阵做投影变换 |
| 稀疏化 | Sparsification | 将矩阵中不重要的元素置为 0（神经元休眠状态） |
| 稀疏矩阵 | Sparse Matrix | 大部分元素为 0 的矩阵，运算成本低 |
| 灾难性遗忘 | Catastrophic Forgetting | 多任务合并时模型忘记了之前学到的知识 |
| 内积近似正交 | Approximate Orthogonal | 高维空间中随机向量内积 ≈ 0，意味着互不干扰 |

---

## 3. 技术原理 / 流程拆解

### 3.1 LoRA → LoRI 的演进

```
LoRA:
  原始权重: W (d×d)
  ΔW = B × A  (B: d×r, A: r×d, r << d)
  A 和 B 都参与训练

LoRI:
  ΔW = B_sparse × A_frozen
  A 冻结（随机初始化，不更新）
  B 稀疏化（大部分元素置为 0）
  → 只更新 B 中的非零元素
```

### 3.2 核心改进机制

```
LoRA 的问题：
  1. 多任务合并时灾难性遗忘严重
  2. 仍有参数冗余和内存开销

LoRI 的解决方案：
  1. 冻结 A → 消除 A 的存储和计算需求
  2. 稀疏化 B → 将 B 中大部分元素置为 0 → 进一步减少计算量
  3. A 固定且高维随机 → 不同任务的 ΔW 近似正交 → 多任务可简单串联
```

**参数效率对比（以 LoRA 为基准）：**
| 方法 | 可训练参数占比 | 相比 LoRA |
|------|---------------|-----------|
| 全参数微调 | 100% | — |
| LoRA | ~5% | 减少 95% |
| **LoRI-S (90% 稀疏)** | **~0.25%** | **再减少 95%** |

### 3.3 为什么冻结 A + 稀疏化 B 可行？

```
LoRA 的原始思想：ΔW = B × A
  - A 负责"降维投影"（随机初始化）
  - B 负责"任务适配"（学习增量）

LoRI 的洞察：
  - A 只是投影矩阵，随机初始化就够用 → 不需要训练
  - B 决定任务方向 → 训练 B 即可
  - 高维随机向量之间内积 ≈ 0 → 不同任务的 ΔW 不互相干扰
```

### 3.4 多任务性能对比

| 指标 | 单任务 LoRA | 多任务 LoRA | 多任务 LoRI |
|------|-----------|-----------|-----------|
| Safety（安全性） | 72.8 | 70.9 | **97.5** |
| NLU（自然语言） | 相近 | 相近 | 相近 |
| Code（代码） | 62 | 22 | **~62** |

**安全性 97.5 的含义**：LoRI 对原模型的破坏极小，几乎完美继承了预训练模型的参数。

## 4. 训练与合并

```
LoRA 多任务合并（串联）：
  任务1: ΔW₁ = B₁ × A₁
  任务2: ΔW₂ = B₂ × A₂
  合并: W + ΔW₁ + ΔW₂ → 灾难性遗忘严重

LoRI 多任务合并（串联）：
  任务1: ΔW₁ = B₁_sparse × A_frozen（A 相同！）
  任务2: ΔW₂ = B₂_sparse × A_frozen
  合并: W + (B₁ + B₂)_sparse × A_frozen → 近似正交，互不干扰
```

---

## 5. 避坑指南

| 注意点 | 说明 |
|--------|------|
| "稀疏化"不是随机删除 | 是让 B 中大部分元素变成 0（不是删除整个矩阵） |
| A 冻结的前提是随机初始化 | 如果用预训练值初始化 A 再冻结，效果会不同 |
| 高维内积≈0 是统计意义上的 | 不是绝对为 0，但高维时近似成立 |
| LoRI 目前不如 LoRA 普及 | 但未来小模型个人微调场景下会越来越重要 |

---

## 6. 对比与思考

### 6.1 LoRA vs LoRI

| 对比 | LoRA | LoRI |
|------|------|------|
| A 矩阵 | 训练 | **冻结**（随机初始化） |
| B 矩阵 | 训练 | **训练 + 稀疏化** |
| 可训练参数 | ~5% | ~0.25%（再减 95%） |
| 多任务合并 | 灾难性遗忘严重 | **近似正交，可简单串联** |
| 安全继承 | 一般 | **97.5%（极高）** |

### 6.2 老师对 LoRI 的评价

> "LoRI 以后肯定会有大作用。企业面试现在问 LoRA 的多，但你可以多关注这个方向——未来两三年微调的地位会比现在高很多。小模型 + 个人定制化绝对是以后的重点方向。"
