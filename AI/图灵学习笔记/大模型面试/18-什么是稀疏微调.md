# 什么是稀疏微调（Sparse Fine-Tuning）

## 1. 课程元信息

- **主题**：稀疏微调的核心概念、实现方式与典型应用（LoSA）
- **前置知识**：PEFT、剪枝、LoRA
- **核心目标**：理解稀疏微调"只更新关键参数"的思想，以及与剪枝/LoRA 的关系

---

## 2. 核心概念图谱

| 术语 | 英文 | 通俗解释 |
|------|------|---------|
| 稀疏微调 | Sparse Fine-Tuning | 只更新模型中的部分关键参数，其余冻结 |
| 稀疏度 | Sparsity Ratio | 被置为 0 的参数比例，通常 70%~90% |
| 结构化修剪 | Structured Pruning | 按块/行/列删除参数，保持规则零值模式 |
| LoSA | Long Short-range Adapter | 长短适配器，稀疏微调 + LoRA 的融合方案 |
| 动态稀疏 | Dynamic Sparsity | 训练过程中稀疏模式可变化的策略 |

---

## 3. 技术原理 / 流程拆解

### 3.1 稀疏微调的核心思想

```
全量微调：更新矩阵中每一个参数
               ↓
稀疏微调：只更新矩阵中的"关键路径"，其余冻结

矩阵比喻（3×3）：
  全量微调：更新全部 9 个格子
  稀疏微调：只更新对角线 3 个格子 → 其余 6 个不变
```

**稀疏微调的三步流程：**

```
Step 1: 结构化剪枝
  → 对权重矩阵分块，按规则删除冗余参数（如每 4 个保留 2 个）

Step 2: 迭代优化
  → 逐步增加稀疏度，同时监测精度变化
  → 在保留预训练知识的前提下最大化稀疏

Step 3: 任务适配
  → 使用下游任务数据，对稀疏后的模型进行微调
  → 梯度只更新剩余的非零参数
```

### 3.2 稀疏微调 vs 剪枝 vs LoRA

| 对比 | 剪枝 | 稀疏微调 | LoRA |
|------|------|---------|------|
| 核心操作 | 删除不重要参数 | 只更新关键参数 | 低秩分解后训练 |
| 参数是否消失 | 是（物理删除） | 否（置 0 但保留结构） | 否（新增参数） |
| 稀疏度 | 10%~90% | 70%~90% | 不直接稀疏 |
| 推理加速 | ✅ 结构化剪枝友好 | ✅ 规则零值模式 | ❌ 无直接加速 |
| 精度影响 | 可能较大 | 极小 | 极小 |

### 3.3 LoSA（长短适配器）— 稀疏微调的典型应用

```
每层 Transformer 的输出 → 同时送入两个适配器：
  ├── Short-range Adapter（短适配器）→ 捕捉局部时序特征
  └── Long-range Adapter（长适配器） → 捕捉长距离依赖
  
  → 两个适配器的输出通过 Projection Layer 合并
  → 送入下游任务头（如 TAL 定位头）
```

**核心洞察**：将每一层的 K/V 分别送入长短适配器做交叉注意力，再用共享的 Query 合并结果。

## 4. 效果与优势

| 效果 | 数据 |
|------|------|
| 推理速度 | 稀疏模型在 CPU 上推理速度提升 2 倍以上 |
| 精度影响 | 极小（70%~90% 稀疏度下精度几乎不变） |
| 压缩能力 | 结合量化/蒸馏可压缩 10~100 倍 |
| 多领域适配 | NLP / CV / 语音生成均适用 |

---

## 5. 本节课思维导图

- 稀疏微调
  - 定义：只更新关键参数，其余冻结
  - 三步流程：剪枝 → 迭代优化 → 任务适配
  - vs 剪枝：不删除参数，只置 0（保留结构）
  - vs LoRA：直接稀疏化原参数，不新增
  - 典型应用：LoSA（长短适配器）
  - 优势
    - 推理速度 2 倍+
    - 精度影响极小
    - 结合量化/蒸馏可压缩 10-100 倍
