# 残差网络（ResNet）有什么作用

## 1. 课程元信息

- **主题**：残差网络（ResNet）的核心思想 — 残差学习与跳跃连接
- **提出者**：何凯明等人，2015 年，ImageNet 图像分类比赛冠军
- **前置知识**：卷积神经网络（CNN）基础、梯度消失/爆炸

---

## 2. 核心概念图谱

| 术语 | 英文 | 通俗解释 |
|------|------|---------|
| 残差网络 | Residual Network (ResNet) | 通过跳跃连接让网络可以堆叠到极深（100+ 层）的架构 |
| 残差 | Residual | 目标值与输入值之间的差值，即"还差多少" |
| 跳跃连接 | Skip Connection / Shortcut | 将输入直接跳过若干层与输出相加 |
| 残差块 | Residual Block | 包含卷积层 + 跳跃连接的基本结构单元 |
| 退化问题 | Degradation Problem | 网络深度增加后精度反而下降，不是过拟合导致的 |
| 恒等映射 | Identity Mapping | 输入等于输出的映射（F(x) → 0） |
| 瓶颈残差块 | Bottleneck Block | 1×1 降维 → 3×3 卷积 → 1×1 升维，深层 ResNet 使用 |

---

## 3. 技术原理 / 流程拆解

### 3.1 什么是残差（直观理解）

```
模糊图片 + [残差蒙版] = 清晰图片

残差 = 清晰图片 - 模糊图片
     = "还差多少才能变清晰"
```

在神经网络中，不直接学习目标的完整映射 `H(x)`，而是学习残差 `F(x) = H(x) - x`：

```
传统网络：学习 H(x) = 目标映射
ResNet：  学习 F(x) = H(x) - x，再通过 F(x) + x 得到 H(x)
```

### 3.2 残差块结构

```
        输入 x
          │
    ┌─────┴──────┐
    │  卷积层     │
    │  ReLU       │
    │  卷积层     │
    └─────┬──────┘
          │ F(x)
          │
          └──── + ──── → H(x) = F(x) + x
               ↑
          输入 x（跳跃连接）
```

**两种残差块：**

| 类型 | 结构 | 适用层数 |
|------|------|---------|
| **基础残差块** | 3×3 Conv → ReLU → 3×3 Conv | ResNet-18 / ResNet-34 |
| **瓶颈残差块** | 1×1 降维 → 3×3 Conv → 1×1 升维 | ResNet-50 / ResNet-101 / ResNet-152 |

### 3.3 解决了什么问题？

```
传统深层网络的问题：
  层数增加 → 精度先升后降（即使没有过拟合）
  原因：梯度在反向传播中层层衰减 → 底层参数难以更新

ResNet 的解决方案：
  跳跃连接让梯度可以直接传递到浅层
  梯度 = d(F(x)+x)/dx = dF(x)/dx + 1
  "1" 这条通路确保梯度永远不会完全消失
```

### 3.4 跳跃连接的三大作用

| 作用 | 说明 |
|------|------|
| **缓解梯度消失** | 梯度可通过跳跃连接直接传到浅层，无需通过所有卷积层 |
| **简化学习目标** | 当最优映射接近恒等映射时，`F(x)` 只需学习接近 0 的小值 |
| **保留底层特征** | 输入 x 作为"锚点"直接传递到深层，避免底层特征被稀释 |

---

## 4. 避坑指南

| 注意点 | 说明 |
|--------|------|
| 退化 ≠ 过拟合 | 深度增加的精度下降是梯度问题，不是过拟合 |
| ResNet 不是越深就一定更好 | 只是突破了深层训练的技术瓶颈，让深度不再是限制 |
| 跳跃连接中的 `+x` 要求维度相同 | 如果卷积层改变了通道数，需要 1×1 卷积调整 x 的维度 |
| Transformer 中的残差连接源自 ResNet | 已成为深度学习标准组件 |

---

## 5. 对比与思考

### 5.1 传统网络 vs ResNet

| 对比 | 传统深层网络 | ResNet |
|------|------------|--------|
| 学习目标 | 直接学习 H(x) | 学习残差 F(x) = H(x) - x |
| 梯度传递 | 逐层衰减 | 跳跃连接直达，梯度 = dF/dx + 1 |
| 最大有效深度 | 20~30 层 | 100+ 层 |
| 对视觉领域影响 | 深度受限 | 成为 CV 基础架构 |

### 5.2 残差连接在 Transformer 中的体现

Transformer 中每个子层（注意力/FFN）都包含：
```
output = LayerNorm(x + Sublayer(x))
```
这正是从 ResNet 的跳跃连接继承而来的设计。

    - 缓解梯度消失
    - 简化学习目标
    - 保留底层特征
  - 影响
    - 突破深度限制（100+ 层）
