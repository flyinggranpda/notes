# PEFT 与 LoRA 笔记

## 一、微调基础回顾

### 微调最重要的三件事

1. **高质量数据集** — 数据质量是微调中最重要的因素
2. **三步走**：找基座模型 → 找数据集 → 用微调框架融合
3. 了解不同微调框架的差异（如 Unsloth 比其他框架快很多）

### 微调 vs 提示工程的三个优势

1. **更多输入** — 微调不限于上下文长度，可以把所有内容都训练进去（如小说作者将自己的全部作品调教给模型）
2. **更精确稳定的回答** — 如医疗场景，希望模型严格输出特定答案，减少幻觉
3. **复制特定风格** — 扮演具体人物时，通过大量语料让模型学会其说话习惯，而提示词难以精确描述

---

## 二、PEFT 概述

**PEFT = Parameter Efficient Fine Tuning**，高效参数微调。

目标：让微调速度更快，占用显存更小。

Unsloth 框架的核心优化之一就是 **LoRA**，它宣称：
- 训练速度提升 30 倍
- 内存节省 60%
- 精度损失几乎为零

---

## 三、神经网络在训练什么？

### 训练结果就是一堆浮点数

无论神经网络多复杂，训练的结果最终都存储在参数中 — 一堆 float 浮点数，也叫权重（weight）、参数（parameter）、张量（tensor）。

代码层面，一个神经网络的 `layer` 结构体最终就是在更新 `out_w`（输出权重）和 `bias`（偏差），本质就是读写 float 数组。

### 为什么参数能存储语言理解？

以"苹果、葡萄、瓜子"三个词为例：
- **输入编码**：用 one-hot 编码将词转为二进制向量
- **输出编码**：用概率向量描述词的属性（是否是水果、甜度、含水量等）
- **训练**：求一个矩阵，使得输入 × 矩阵 = 输出

这个矩阵就是"理解"的载体。当输入一个新词（如"荔枝"），经过矩阵计算后落在向量空间中与"苹果""葡萄"相近的位置，模型就能推断它大概率也是水果 — 这就是 **embedding**（词嵌入）。

### 为什么不用直接求解，要用逼近？

因为样本永远有限，直接求解会导致**过拟合** — 模型只记住了训练数据，无法泛化到未见过的数据。神经网络通过近似拟合出一条"柔和的曲线"，反映数据背后的内在规律，而不是硬连接训练点。

## 四、LoRA (Low Rank Adaptation)

### 核心思想

| 缩写 | 含义 |
|------|------|
| Low | 低的、小的 |
| Rank | 秩（矩阵的信息量） |
| Adaptation | 适配（像变色龙一样调整自己） |

**流程**：从高维空间 R^d 开始 → 先降维到较小的 R^r（r < d）→ 再恢复到 R^d。先变小再变大，最后与原始权重相加。

### Rank（秩）是什么

秩是**矩阵的信息量**。例如：
- 第一行 [1, 2, 3]
- 第二行 [2, 4, 6]（等于第一行 × 2，无新信息）
- 第三行 [0, 0, 0]
- 秩 = 1（只有一行有效信息）

**Low rank = 减少矩阵的信息量**，把大矩阵压缩成小矩阵，从而更快训练、更省显存。

### 为什么可以对微调降秩，但不能对基座模型降秩？

- **基座模型**：用 15T 数据训练，信息量极大，秩已最大化，不能降
- **微调**：通常只有几百到几万条数据，信息量很小，降秩是理所应当的

本质：**让要调整的参数量与信息量相匹配** — "多大屁股穿多大裤衩"。

### LoRA 的工作原理

1. 原始推理：输入 X → 乘以原始权重 W → 输出
2. LoRA 推理：输入 X → 同时经过原始权重 W 和 LoRA 适配器（两个小矩阵 A × B）
3. 两个分支的结果**相加**得到最终输出

```
output = X @ W + X @ (A @ B) * alpha
```

LoRA 并不直接修改原始权重，而是把"差值"（delta weight）写在旁边，最后叠加使用。

### 矩阵分解

一个大矩阵可以被分解为两个更小的矩阵相乘（如 3×3 分解为 3×1 和 1×3），小矩阵的参数数量远少于原始矩阵，训练起来更快。

## 五、LoRA 参数详解

### 1. `r` — Rank（秩）

- 要降到的秩的大小
- **推荐值**：8、16、32（128 已偏大，64 也常见）
- 从 8 或 16 开始试，能满足需求就不必增大
- 若设得和原矩阵一样大，就等价于全量微调（Full Fine Tuning）

### 2. `target_modules` — 目标模块

- 指定要对 Transformer 的哪些层应用 LoRA
- 可选：Q、K、V、O（输出层）、MLP 层等
- 论文作者实验结论：**Q 和 V 是最有效的**，显存有限时可只保留这两个

### 3. `lora_alpha` — 缩放因子

- 控制 LoRA 对原始权重的影响程度
- 公式中：`delta_weight = A × B × alpha`
- alpha 越大，影响越大（步子大），但容易过拟合
- alpha 越小，影响越小，更精细

### 4. `dropout` — 丢弃率

- 防止过拟合的正则化手段
- 训练时随机丢弃部分数据，迫使模型学到更通用的规律
- **反直觉**：数据越少，越需要 dropout（因为数据少时更容易过拟合）
- 推荐范围：0.01 ~ 0.1（很小）
- 默认通常为 0（不丢弃）

## 六、LoRA 的变体

### 1. RS LoRA (Rank-Stabilized LoRA)

- `use_rslora = True` 时启用
- 将 lora_alpha 除以 sqrt(r)，即：
  ```
  delta_weight = A × B × alpha / sqrt(r)
  ```
- 由于除以了 sqrt(r)，影响更小、更精细
- 精度更高，但训练稍慢一些

### 2. LoftQ — 更好的初始化

- 默认 LoRA 的 A、B 矩阵用随机值或零初始化
- LoftQ 通过量化框架找到更好的初始值，加速训练
- 代价：初始化本身需要额外计算时间
- 效果取决于具体场景（depend）

### 3. Adaptive LoRA（自适应 LoRA）

- 动态分配每个层的 rank
- 通过**奇异值分解（SVD）**评估每个矩阵的重要性
- 奇异值越大 → 矩阵越重要 → 分配更大的 rank
- 奇异值越小 → 分配更小的 rank
- 不同层、不同矩阵（Q、K、V、O）的 rank 可以不同

### 4. Long LoRA

- 让模型支持更长的上下文
- 在微调时使用分区的 local attention 替代全局 attention
- 可将 7B 模型从 4K 扩展到 100K 上下文
- 但已被 Unsloth 的梯度检查点等新技术超越

## 七、LoRA 的优缺点

### 优点

| 特性 | 说明 |
|------|------|
| 参数少 | 如 8B 模型只需训练 256 个参数（16×16），而非 8B |
| 省显存 | 参数全部放在显存中计算，少参数意味着少显存 |
| 计算快 | 参数少 → 前向/反向传播都快 |
| 模块化 | 可以叠加多个 LoRA（如一个控制中国风、一个控制发型），可分离可合并 |

### 缺点

- **理论上精度略低于全量微调**
- 但在实际实验中，如果 LoRA 的参数规模适当（如 37M 参数），精度甚至可以反超全量微调
- 原因猜想：奇异值分解保留了矩阵中最有代表性的值，微调这些"精华"参数反而更高效
