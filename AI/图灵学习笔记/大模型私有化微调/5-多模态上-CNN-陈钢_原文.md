# 多模态模型（一）：基于CNN的多模态模型

## 一、量化回顾（上节课内容总结）

量化是将模型参数从高精度（如 FP16、FP32）映射到低精度（如 INT8、INT4）的技术，目的是减少模型大小、降低推理成本。经过量化，模型的精度会有一定损失，但在实际应用中通常可接受。

---

## 二、什么是多模态

### 2.1 模态的定义

**模态（Modality）** 是一种"体验或做事的方式"。人类有五种感官：
- 视觉（sight）
- 听觉（hearing）
- 触觉（touch）
- 嗅觉（smell）
- 味觉（taste）

每一种都是不同的模态。为了实现真正的通用人工智能（AGI），AI 也需要具备处理多种模态的能力。

### 2.2 多模态的典型应用

| 模态组合 | 应用场景 |
|---------|---------|
| 语音 + 图像 | 视频理解、视频分析 |
| 文本 + 图像 | 文档分析、图文问答 |
| 文本 + 语音 | 语音助手、语音翻译 |

### 2.3 核心思想：一个 Embedding 统一所有模态

将不同模态的数据映射到同一个向量空间：

- **word2vector** — 文本 → 向量
- **image2vector / vision encoder** — 图像 → 向量
- **voice2vector / audio encoder** — 语音 → 向量

> **核心逻辑：** 当所有东西都变成向量之后，模态之间就可以相互通信。不同模态的向量在同一个空间中可以进行相似度计算、跨模态检索等操作。

## 三、常见多模态任务

### 3.1 VQA（Visual Question Answering，视觉问答）

给模型一张图片，问关于这张图片的问题。例如：
- "图片里有没有猫？"
- "图中有几只猫？"
- "图中的人在干什么？"

### 3.2 Image Captioning（图像描述）

输入一张图片，模型输出一段描述文字（即自动为图片配字幕）。

### 3.3 OCR（光学字符识别）

从图片中识别出文字信息。

### 3.4 Document QA（文档问答）

从收据、发票等文档中提取信息，回答关于文档内容的问题。

### 3.5 实现方式

- **Pipeline 方式：** OCR 提取文字 → 将文字传给大模型 → 大模型回答问题（多阶段串联）
- **端到端方式：** 直接将图片输入到多模态模型中，模型自行完成识别和回答（一体化）

## 四、图像基础

### 4.1 图像的数字化表示

- 图像由像素点（pixel）组成
- 每个像素的值构成矩阵
- 灰度图：单通道矩阵（每个像素一个值 0-255）
- 彩色图：三通道矩阵（R、G、B 三个通道）

> **一句话总结：** 图像在计算机中就是一个数字矩阵（或多通道矩阵的组合）。

### 4.2 特征提取的必要性

- 人类识别物体依靠形状和上下文
- 神经网络无法直接理解原始像素——它看到的只是一堆数字
- 需要将原始像素转化为有意义的**特征（features）**——更高的语义抽象

---

## 五、卷积神经网络（CNN）

### 5.1 卷积核

**卷积核（Convolution Kernel）** 是一个小型矩阵，在图像上滑动并与对应区域的像素做点积运算，用来检测特定的特征（如边缘、纹理、颜色变化）。

#### 边缘检测原理

边缘 = 像素值的剧烈变化 → 可以通过**导数（变化率）**来检测。

- **一维卷积：** 相邻像素求差值 → 检测一维序列的变化点
- **二维卷积：** 在二维图像上，卷积核对水平和垂直方向的变化同时敏感

#### 不同卷积核的效果

| 卷积核类型 | 效果 |
|-----------|------|
| 锐化核 | 增强图像细节，使边缘更清晰 |
| 模糊核 | 平滑图像，去除噪声 |
| 边缘检测核 | 提取图像中的轮廓和边界 |

#### 多核并行

实践中，CNN 会使用 **32 个或更多**不同的卷积核，并行卷积得到 32 张不同的**特征图（Feature Map）**，每张特征图捕捉图像的不同方面信息。

### 5.2 池化（Pooling）

**池化**的目的是在保留重要特征的前提下缩小图像尺寸。

- **最大池化（Max Pooling）：** 在滑动窗口中取最大值，保留最显著的特征
- 池化可以移除无关细节，增强模型的鲁棒性和泛化能力

> **为什么缩小反而更好：** 小的特征图去除了一些不重要的细节，让模型专注于核心特征，反而更容易识别。

### 5.3 Flatten（展平）

将二维的特征图展平为一维向量，作为全连接神经网络的输入。

### 5.4 CNN 的整体架构

```
输入图像 → [卷积 → 池化] × N → Flatten → 全连接神经网络 → 输出
```

- **卷积部分：** 负责特征提取（从原始像素中提取高级语义特征）
- **神经网络部分：** 负责基于特征进行学习和决策

### 5.5 经典 CNN 模型

早期经典：LeNet-5、AlexNet、VGGNet、ResNet 等，为图像识别和计算机视觉奠定了基础。

## 六、CNN 与 Vision Transformer（ViT）对比

| 特性 | CNN | ViT (Vision Transformer) |
|------|-----|--------------------------|
| 特征提取方式 | 手工设计的卷积核 | 将图片分割成 patch + 位置编码 |
| 感受野 | 局部（受卷积核大小限制） | 全局（Self-Attention 关注全部区域） |
| 数据需求 | 小数据集即可训练 | 需要大规模数据 |
| 可扩展性 | 数据量增大时性能提升有限 | 数据量越大，效果越好（远超 CNN） |
| 计算成本 | 低，适合边缘设备 | 高 |
| 适用场景 | 摄像头、嵌入式设备等成本敏感的端侧设备 | 云端大规模模型 |

> **一句话总结：** CNN 轻量高效、适合小数据和端侧部署；ViT 需要更多数据但上限更高，适合大模型场景。

---

## 七、Transformer 在多模态模型中的两种应用方式

1. **替换 CNN 中的 C（特征提取部分）：** 用 ViT Encoder 替代原来的卷积部分来提取图像特征
2. **替换 CNN 中的 NN（神经网络部分）：** 用语言模型 Transformer 替代全连接神经网络，进行更高层次的语义理解和生成

---

## 八、Qwen-VL 架构

Qwen-VL 是多模态大模型的典型代表，其架构为：

```
图像 → Qwen-VL 专用 ViT Encoder（改进版） → Qwen LLM → 输出
```

### 8.1 ViT Encoder 的改进

- **Window Attention（窗口注意力）：** 只在局部窗口内做注意力计算，降低计算复杂度
- **Dynamic Resolution（动态分辨率）：** 支持不同尺寸的输入图片，更灵活

### 8.2 使用 LLM 作为后端（Backend）的优势

- **世界知识（World Knowledge）：** LLM 拥有丰富的预训练知识，模型不仅能识别出图片中是"一个拿球的人"，还能识别出"这是迈克尔·乔丹"
- **工具复用：** 可以直接复用现有的 LLM 微调工具链，如：
  - **LoRA（Low-Rank Adaptation）：** 高效微调技术
  - **Q-LoRA（Quantized LoRA）：** 量化 + LoRA 结合的微调方式

---

## 九、总结

CNN 是多模态模型的基石，从图像特征提取出发，逐步发展到与现代 Transformer 架构融合。ViT 作为 CNN 的替代方案带来了全局感受野和更强的扩展性，而 Qwen-VL 等模型则结合了 ViT 编码器与 LLM 后端的优势，实现了更强大的多模态理解能力。在实际应用中，CNN 仍然在端侧场景中发挥着不可替代的作用。
