# 多模态模型（下）—— 基于 Transformers 的模型与图像生成

## 一、微调多模态模型实战：Qwen-VL 做 LaTeX OCR

### 1.1 与纯文本微调的区别

使用 unsloth 微调 Qwen-VL（通义千问 2.5 7B 多模态版本），与纯 LLM 微调有两点主要不同：

- **需安装 torchvision**：torch 不自动依赖 torchvision，需要手动匹配版本。例如 torch 2.6 对应 torchvision 0.21，需指定版本安装。
- **数据集包含图像**：数据集的输入是 image，输出是 text（LaTeX 代码），而非纯文本对。

### 1.2 数据集介绍

使用 LaTeX OCR 数据集，包含 image + LaTeX 代码对：

- 输入：公式图片
- 输出：对应的 LaTeX 代码（一种用文字表达数学公式的编程语言）
- 验证方式：Python 内置的 LaTeX 库可将文本渲染为图片，与原图对比即可判断是否正确

### 1.3 微调前后对比

- **微调前**：Qwen-VL 会"假模假式"地输出 LaTeX 代码，但经 Python 验证是不合法的——属于幻觉。
- **微调后**：模型能输出合法的 LaTeX 代码，经 Python 渲染与原图一致。

### 1.4 总结

多模态大模型微调与 LLM 微调大同小异，主要区别：
1. 底层依赖多了一个 `torchvision`
2. 数据集中包含 `image` 字段

## 二、原生多模态模型（Native Multimodal Models）

### 2.1 概念

"原生多模态"（native multimodal）是各大厂共同认可的概念。其反义词是"后天习得的"（grounded）。

| 厂商 | 定义角度 | 核心观点 |
|------|----------|----------|
| **OpenAI (GPT-4o)** | 产品角度 | 能接受任意组合的文字、音频、图像、视频输入，并生成任意组合的文字、音频、图像输出 |
| **Google (Gemini)** | 技术角度 | 模型在训练时就同时涵盖 text、image、audio、video 数据 |
| **Meta (Llama 4)** | 架构角度 | 使用 **early fusion**（早期融合）架构实现 |

### 2.2 多模态的五条技术路线

#### ① 联合表示（Joint Representation）
将不同模态的同一事物表示到同一个向量空间中（如：文字的"苹果"和图像的"苹果"在向量空间中对齐）。

#### ② 对齐（Alignment）
- **显式对齐**：通过某个算法，明确将一个模态中的 token 对应到另一个模态的 token。
- **隐式对齐**：将对齐逻辑隐藏在神经网络内部（如 YOLO 将检测框对齐到图像区域），无法明确解释。

#### ③ 融合（Fusion）
- **早期融合（Early Fusion）**：不同模态的数据在输入阶段就 tokenize 成统一格式，送给同一个模型处理（端到端）。Meta Llama 4 即采用此方式。
- **晚期融合（Late Fusion）**：各模态先分别通过独立的网络识别处理，最后将结果融合。

#### ④ 转换（Translation）
类似字典映射，将一种模态的内容直接映射到另一种模态。

#### ⑤ 迁移学习（Transfer Learning）
通过微调（fine-tuning）让模型跨模态迁移知识。本质上，微调就是一种迁移学习的方式。

### 2.3 原生多模态 vs. Grounded 多模态

**Qwen-VL 不是原生多模态**，而是 **grounded（接地）** 的多模态模型：

- 基座 LLM（Qwen 2.5）先独立训练好，之后再在下面接入 Vision Encoder 等模块——是在已有的"果园"上再"种一棵树"。
- 真正的原生多模态应满足三个特征：
  1. **输出自带多模态内容**：不仅能理解图片输入，还能主动生成图片、表格等多模态回复
  2. **基座训练时就包含多模态数据**：模型从 0 到 1 的训练过程就同时处理文字和图像
  3. **自带多模态编解码器**：模型原生就包含处理图像/音频等模态所需的编码器（如 VIT）

### 2.4 争议与现状

- 原生多模态概念偏商业和营销，架构上本质是"VIT 放在外面还是里面"的区别。
- 号称原生多模态的模型（如 Llama 4）在开源社区的选用率相对较低。

## 三、图像生成模型（一）：GAN 对抗生成网络

### 3.1 基本概念

**浅空间（Latent Space）**：图像最核心的特征/规律的抽象空间。类似于人的潜意识——表面行为多种多样，但背后由共同的潜意识驱动。两张像素完全不同的图（如中世纪男人 vs 石器时代小孩），在浅空间中的表达可能相近（都是"人"）。

**GAN（Generative Adversarial Networks）**：包含两个神经网络——生成器（Generator, G）和判别器（Discriminator, D）。

### 3.2 训练过程

```
真实图片 ──→ 判别器 D ──→ 真假判别
                ↑  ↑
随机噪声 → 生成器 G → 假图片 ──┘
```

1. **训练判别器 D**：
   - 真实图片打标签 1.0
   - 生成器造的假图片打标签 0.x
   - D 通过分类 loss 训练，不断提高判别真伪的能力

2. **训练生成器 G**：
   - G 生成假图片，送给 D 打分
   - D 返回的分数作为 G 的训练信号（loss）
   - G 不断调整参数，提高得分

3. **两个网络同时训练，互相成就**：
   - D 辨别真伪的本领越来越高
   - G 伪造真图的本领也越来越高
   - 训练终点：D 无法可靠区分真假（概率接近 50/50）

### 3.3 GAN 的问题

- **无用户控制**：G 的输入只是随机噪声 + 浅空间，用户无法指定要生成什么内容。
- **训练不稳定**：
  - D 太强：G 的每次得分都是 0.1，无法获得有效梯度
  - G 太强：D 完全无法区分，无法训练
  - 需要两者水平相当，才能共同成长

### 3.4 StyleGAN（风格迁移）

在生成器的每一层加入**动态输入**——风格向量，让生成过程受另一张图的浅空间特征影响：

- 原始 G 的各层：Conv → Normalize → FC → UpSample → Conv → ...
- StyleGAN：在上述各层中额外注入一个风格编码（来自另一张图的浅空间）
- 效果：在生成图像的同时，受参考图的风格影响，实现**风格迁移**

### 3.5 CycleGAN（循环一致性 GAN）

使用**两个生成器 + 两个判别器** + 循环一致性损失（cycle consistency loss）：

- 将 X 域图像映射到 Y 域（如真实图 → 漫画风）
- 再将 Y 域图像映射回 X 域（漫画风 → 真实图）
- 要求往返映射后与原图一致，从而保证映射只改变了风格，没有改变内容
- 比 StyleGAN 更专注于风格迁移，效果也更强

> GAN 目前主要用于风格迁移领域，图像生成的主流已转向扩散模型。

## 四、图像生成模型（二）：扩散模型（Diffusion Models）

### 4.1 核心原理

**扩散** = 正向过程：给图像逐步添加噪声，直到完全模糊。
**反扩散** = 逆向过程：从纯噪声开始，逐步去噪，还原出清晰图像。

#### 训练过程

1. 取一张真实图像
2. 人为添加已知的噪声
3. 让神经网络**预测加入的噪声**
4. 用 L1 Loss 比较真实噪声与预测噪声
5. 目标：网络能准确预测每一步添加的噪声

#### 推理过程

1. 从随机噪声开始
2. 神经网络预测该步的噪声
3. 减去预测的噪声，得到更清晰的图像
4. 重复上两步（通常 20-1000 步）
5. 最终得到清晰的生成图像

### 4.2 Stable Diffusion 三大创新

#### 创新一：CLIP 对齐

CLIP（Contrastive Language-Image Pre-training）由 OpenAI 提出，实现文字与图像的对齐：

- 文本通过 text encoder 得到向量
- 图像通过 image encoder 得到向量
- 将两组向量映射到同一空间进行匹配
- 作用：让用户可以用文字 prompt 控制图像生成

#### 创新二：UNet 架构

U 型网络结构，核心思想：**收缩时保存细节，扩展时还原细节**。

```
输入 → [Conv + Pooling] 缩小 → 保存特征A
     → [Conv + Pooling] 再缩小 → 保存特征B
     → ... → 最小特征空间
     → [UpSample + 特征B] 放大
     → [UpSample + 特征A] 放大
     → 输出
```

- **编码器（下采样）**：卷积 + Pooling 逐步缩小图像，提取核心特征
- **解码器（上采样）**：UpSample 逐步放大，并在每一层加上编码阶段保存的细节特征
- **跳跃连接**：将编码阶段保存的特征拼接到解码阶段的对应层，保持细节不丢失

优势：
- 在更小的特征空间上计算，速度大幅提升（1000 步 → 50-100 步）
- 更易实现风格迁移——可在跳跃连接处"作弊"，加入其他图片的风格特征

#### 创新三：VAE（变分自编码器）

- **像素空间** → **浅空间**（VAE 编码器压缩）→ 在浅空间上做 UNet 处理 → **像素空间**（VAE 解码器还原）
- 将 1024×1024 的图像压缩到 16×16 的浅空间处理，再还原回来
- 优势：处理速度更快，支持更高分辨率的图像

### 4.3 Stable Diffusion 整体架构

```
文本 Prompt → [CLIP] → 文本向量 ──┐
                                  ├──→ [UNet] → [VAE 解码] → 生成图像
图像 → [VAE 编码] → 浅空间 ────────┘
（训练时）         （UNet 在浅空间去噪）
```

三个组件的分工：
- **CLIP**：理解文本提示词，将其与图像特征对齐
- **UNet**：在压缩后的浅空间中进行去噪（反扩散）
- **VAE**：压缩像素空间（编码），还原像素空间（解码）

## 五、扩散模型的微调方法（4 种）

| 方法 | 原理 | 适用场景 |
|------|------|----------|
| **全量微调** | 修改原始模型所有参数 | 最贵，效果最好 |
| **LoRA** | 在 UNet 各层添加 adapter 矩阵，只训练 adapter，不改变原始参数 | 高效、轻量、最常用 |
| **ControlNet** | 用另一个 hyper network 生成 adapter 层，再与原始模型相加 | 控制生成的结构/姿态/动作等 |
| **Text Inversion / Prompt Tuning** | 只修改 text embedding 层的参数，不修改模型本身 | 最轻量，类似 P-Tuning |

### 5.1 LoRA 与 ControlNet 的区别

- **LoRA**：直接新增低秩矩阵，与原始权重相加（addition）。
- **ControlNet**：用另一个独立的神经网络生成 adapter 权重，再与原始模型相加。常用于保留输入图像的结构信息（如姿态、动作骨架），在视频生成中应用广泛。

### 5.2 微调工具

使用 Hugging Face 的 **diffusers** 库加载 Stable Diffusion 模型，配合 PEFT 库进行 LoRA 微调。训练过程通过配置文件交互式完成（如选择 GPU、精度等），最终保存 LoRA 权重文件，推理时加载基座模型 + LoRA 权重即可。
