# 第一部分 · NLP 基础认知

---

## 1.1 🧠 一句话说清 NLP

**NLP（Natural Language Processing，自然语言处理）** 就是让计算机能「听懂人话」—— 不只是把文字当成字符串处理，而是理解其中的**意图、情感、语义**，然后做出有价值的回应。

### 🍳 厨房类比

| 层次 | 人怎么做 | NLP 怎么做 |
|------|----------|-----------|
| 看菜名 | 知道是"番茄炒蛋" | 分词、识别实体 |
| 读菜谱 | 理解"少许盐"是多少 | 语义理解、消歧义 |
| 按步骤做 | 先炒蛋再放番茄 | 序列建模、生成文本 |
| 尝味道调整 | 咸了加点糖 | 反馈优化、微调 |

│  │  │  │ │LLM(大模型)│   │   │   │   │

> **费曼解释**：AI = 让机器变聪明这个目标；ML = 让机器自己学这个方法；DL = 用深层神经网络学这个手段；NLP = 专门处理语言这个方向；LLM = 用超大模型搞定一切语言任务的最新趋势。

### 快速对比表

| 术语 | 英文 | 一句话解释 | 生活类比 |
|------|------|-----------|---------|
| **AI** | Artificial Intelligence | 让机器表现出人类智能 | "造一个聪明的东西" |
| **ML** | Machine Learning | 让机器从数据中自己学规律 | "教它钓鱼，不是给它鱼" |

| **NLP** | Natural Language Processing | 让机器处理和理解语言文字 | "教会计算机中英文" |
| **LLM** | Large Language Model | 海量数据+超大参数训练的语言模型 | "读过全人类文字的超强大脑" |

### ❓ 新手常见问题

- **Q：深度学习就是神经网络吗？** → 基本是的，深度学习 = 有很多层的神经网络。
- **Q：NLP 只用深度学习做吗？** → 早期也用规则和统计方法，但现在主流就是深度学习。
- **Q：LLM 和 NLP 是什么关系？** → LLM 是 NLP 目前最先进的技术路线，不是全部但绕不开。

## 1.3 🎯 NLP 研究的核心难题

| 难题 | 说明 | 例子 |
|------|------|------|
| **歧义** | 同一个词在不同上下文意思完全不同 | "我去**银行**存钱" vs "我在河**岸**散步"；"打"有 20+ 种意思 |
| **结构复杂** | 语言有层次结构 | 词 → 短语 → 句子 → 段落 → 篇章 |
| **创造性** | 人可以写出从未有过的句子 | 机器需要泛化能力而非死记硬背 |

## 1.5 🔄 NLP 的范式演变（重要！）

NLP 经历了三次范式飞跃，这是理解整个领域发展方向的关键：

```
阶段一：任务专用模型（2018 之前）
   情感分析 → 单独训一个模型
   翻译     → 单独训一个模型
   摘要     → 单独训一个模型
   ❌ 每个任务从零开始，成本极高

阶段二：预训练 + 微调（2018 年 BERT 开启）
   ① 先用海量通用数据训练一个大模型（预训练）
   ② 不同任务加少量数据调整（微调）
   ✅ 一个底座，适配多种任务

阶段三：Prompt + 大模型（2022 年 ChatGPT 开启）
   不用微调了，直接用自然语言"告诉"大模型：
   "翻译成英文：……"  →  直接出结果
   "总结这篇文章：……" →  直接出结果
   ✅ 靠提示词指挥大模型，连微调都不需要
```

## 2.2 🔧 规则时代（1950s - 1980s）

### 核心思想
把语法规则写进程序里，让计算机"理解"语言。

### 里程碑

| 年份 | 事件 | 意义 |
|------|------|------|
| 1950 | 图灵测试提出 | 判断机器是否有智能的标准 |
| 1954 | Georgetown-IBM 实验 | 首次机器翻译演示（俄→英，60 个句子） |
| 1966 | ELIZA 聊天程序 | 最早的聊天机器人（模拟心理治疗师） |

### 为什么失败了？

```
输入："The car goes fast."
    ① car → 名词  ② goes → 动词  ③ fast → 副词 ✅

换个句子就崩：
"The fast car goes."     ← fast 在这里是形容词！
"Time flies like an arrow."  ← flies 是动词还是名词？
```

**三大致命问题：**
1. 🚫 **规则写不完** — 语言例外太多（中文尤其）
2. 🚫 **歧义无解** — "我差点没上车" 到底上没上车？
3. 🚫 **无法扩展** — 加新领域就得重写所有规则

---

## 2.3 📊 统计时代（1980s - 1990s）

### 核心转变
> 不让机器"理解"语言，而是让它**统计语言的规律**。

### 🔑 N-gram 模型

**定义**：基于前 N-1 个词预测第 N 个词的概率模型。

| 名称 | N 值 | 含义 | 例子 |
|------|------|------|------|
| **Unigram** | 1 | 只看词本身频率 | "我 爱 你" 里最常出现的词 |
| **Bigram** | 2 | 看前 1 个词 | "爱"后面最可能跟 → "你" |
| **Trigram** | 3 | 看前 2 个词 | "我 爱"后面最可能跟 → "你" |

> 🍳 **费曼理解** = 词语接龙：Unigram 乱接，Bigram 听前一个词决定，Trigram 听前两个词决定。但隔了 5 个词它就看不到了。

### 🔑 Bag of Words（词袋模型 / BoW）

**思想**：文本 = 一堆词的集合，**忽略词序**只看出现情况。

```
句子1："我 爱 北京"
句子2："北京 我 爱"
→ BoW 表示完全相同！因为不关心顺序

词汇表：{我, 爱, 北京, 天安门, 长城}
"我爱北京" → [1, 1, 1, 0, 0]   ← 词频向量
```

| 优点 | 缺点 |
|------|------|
| 简单、直观、计算快 | ❌ 丢失词序 → "我打你"和"你打我"一样 |

---

## 2.4 🤖 机器学习时代（1990s - 2000s）

统计方法效果有限，需要更好的**分类算法**。

### 常用算法

| 算法 | 核心思想 | NLP 应用 |
|------|---------|---------|
| **SVM** 支持向量机 | 高维空间找最佳分类边界 | 文本分类、情感分析 |
| **最大熵模型** | 约束下选最均匀的分布 | 词性标注、句法分析 |
| **CRF** 条件随机场 | 序列标注的"黄金标准" | NER、词性标注 |
| **HMM** 隐马尔可夫模型 | 基于状态转移的序列模型 | 词性标注、语音识别 |

### 传统 NER 流程
```
原始文本 → 特征提取（大小写、前后词、词性）→ ML 模型 → 实体标签
                                          ↑
                                     人工设计特征（特征工程）
```
**痛点**：特征工程依赖专家经验，非常耗时。

---

## 2.5 🧠 深度学习时代（2010 - 2017）

### 突破背景
2012 年 CNN 在图像领域 ImageNet 大胜 → NLP 研究者开始尝试深度学习方法。

### 📌 CNN + NLP
```
"这部电影 非常 好看"
     ↓  （词向量编码 → 卷积 + 池化）
文本分类结果 → 正面 ✅
```
- ✅ 提取局部词组特征（"非常好看"）
- ❌ 长距离依赖效果差

### 📌 RNN（循环神经网络）—— 里程碑 🌟

**创新**：网络有"记忆"，能处理序列数据。

```
输出:     o1 → o2 → o3 → ...
          ↑    ↑    ↑
隐藏层:   h1 → h2 → h3 → ...  ← 记忆传递
          ↑    ↑    ↑
输入:     x1   x2   x3   ...
         "我" "爱" "你"
```

**痛点**：链子太长就断了 → **梯度消失**，记不住太久之前的信息。
> 类比：一个人传悄悄话，传到最后全变样了。

### 📌 LSTM / GRU（长短期记忆）

| | 做了什么 | 类比 |
|--|---------|------|
| **LSTM** | 加了三道门（输入门、遗忘门、输出门），控制记什么忘什么 | 一个带筛选功能的笔记本 |
| **GRU** | 简化成两道门（重置门、更新门），效果差不多参数更少 | LSTM 的轻量版 |

### 📌 Seq2Seq（序列到序列）

**核心**：编码器读完整输入 → 压缩成语义向量 → 解码器生成输出。

```
"我 爱 你" → 编码器RNN → [语义向量] → 解码器RNN → "I love you"
```

**问题**：输入太长，一个语义向量"装不下" → 长句子翻译效果差。

### 📌 Attention 机制（划时代 💡）

**核心**：生成输出时，不再只看最后一个语义向量，而是回头看所有输入位置，**挑重点看**。

> 🍳 **类比**：翻译时不是死记整句话，而是边翻译边看原文对应的位置。

**效果**：解决了长序列信息丢失问题。

## 2.6 ⚡ Transformer 时代（2017 至今）

### 2017 年：分水岭

> 📄 **论文**：Attention Is All You Need（Google，2017）
> **核心**：完全抛弃 RNN，**只用 Attention 机制**

### 思维转变
```
RNN 思路：    一个一个看词，记住前面看过的  ← 串行，慢
Transformer：一眼看完所有词，看出哪些词之间关系密切  ← 并行，快
```

### 关键创新

| 创新点 | 做了什么 | 效果 |
|--------|---------|------|
| **Self-Attention** | 每个词跟句子中所有词计算相关性 | 捕捉长距离依赖 |
| **多头注意力** | 用多个不同角度同时看 | 更丰富的表示 |
| **位置编码** | 给每个词加上位置信息 | 让模型知道词序 |
| **并行计算** | 所有词同时处理 | 训练速度大幅提升 |

### Transformer 架构简化版

```
          输出
            ↑
        解码器层
 ┌────────────────────┐
 │  掩码 Self-Attention │
 │  交叉注意力(Encoder) │
 │  Feed Forward NN    │
 └────────────────────┘
            ↑
        编码器层
 ┌────────────────────┐
 │  Self-Attention     │
 │  Feed Forward NN    │
 └────────────────────┘
            ↑
          输入
```

### 2018 年后：两大分支

```
               Transformer
                    │
       ┌────────────┴────────────┐
       ▼                         ▼
   GPT 系列（Decoder 只用）     BERT 系列（Encoder 只用）
   单向 · 生成 · 预测下一个词    双向 · 理解 · 完形填空
   GPT → GPT-2 → GPT-3 → GPT-4   BERT → RoBERTa → ALBERT
```

**GPT vs BERT 对比**

| 对比维度 | GPT | BERT |
|---------|-----|------|
| 方向 | **单向**（左→右） | **双向**（左右看全局） |
| 擅长 | **生成**（写文章、对话） | **理解**（分类、情感分析、QA） |
| 训练方式 | 预测下一个词 | 遮词预测（完形填空） |
| 全称 | Generative Pre-trained Transformer | Bidirectional Encoder Representations from Transformers |
| 记忆口诀 | "顺着往下编" | "完形填空高手" |

## 3.2 🔵 文本分类（Text Classification）— 最基础

**定义**：给定一段文字，判断它属于哪个类别。

| 应用 | 输入 | 输出 |
|------|------|------|
| 情感分析 | "这产品太烂了" | 负面 ❌ |
| 垃圾邮件检测 | "点击领取百万大奖" | 垃圾邮件 🗑️ |
| 主题分类 | "股市今日大涨" | 财经 📊 |
| 意图识别 | "帮我订张机票" | 预订意图 |

**方法演变**：
```
传统：朴素贝叶斯、SVM
DL：TextCNN、LSTM
当前：BERT（[CLS] token 接分类头）
大模型：直接 Prompt "这句话的情感是正面还是负面？"
```

## 3.3 🟡 命名实体识别（NER）— 🔥 重点

**定义**：从文本中识别出有特定意义的实体（人名、地名、机构名、时间、金额等）。

```
输入："小明昨天去了北京大学，花了200块钱买了本书。"

输出：
[小明]      → 人名 (PER)
[昨天]      → 时间 (TIME)
[北京大学]  → 机构 (ORG)
[200块]     → 金额 (MONEY)
```

### 🏷️ BIO 标注体系（核心！）

BIO 是 NER 中最经典的标注方式，B=实体开始，I=实体内部，O=非实体。

| 标签 | 全称 | 含义 | 例子（"小明在北京大学读书"） |
|------|------|------|---------------------------|
| **B-PER** | Begin-Person | 人名开始 | 小 |
| **I-PER** | Inside-Person | 人名内部 | 明 |
| **B-ORG** | Begin-Organization | 机构名开始 | 北 |
| **I-ORG** | Inside-Organization | 机构名内部 | 京 大 学 |
| **O** | Outside | 非实体 | 在 / 读 / 书 |

**可视化**：
```
文 字： 小  明  在  北  京  大  学  读  书
BIO：  B  I   O   B   I   I   I   O   O
       PER PER    ORG ORG ORG ORG
```

> 🍳 **费曼理解**：就像用荧光笔在文章里划重点 —— B 是下笔那一点，I 是划过去的轨迹，O 是没划到的部分。

**为什么要用 BIO？** 因为实体可能有多个字，需要标记**边界**："北京大学"是 4 个字的机构名，只标"是/否实体"分不清"北京"（城市）和"北京大学"（机构）。

**应用场景**：信息抽取、知识图谱构建、医疗文本（疾病/药物/症状）、金融文本。

---

## 3.4 🟢 词性标注（POS Tagging）— 最经典

**定义**：给句子里的每个词标上词性（名词、动词、形容词……）。

```
输入："我 爱 自 然 语 言 处 理"
输出： 代 动 名 名 名 名 名
      词 词 词 词 词 词 词
```

**作用**：很多下游任务（如句法分析）的基础。

---

## 3.5 🔴 机器翻译（Machine Translation）— 最知名

**定义**：把一种语言的文本自动翻译成另一种语言。

| 阶段 | 代表 | 特点 |
|------|------|------|
| 规则翻译 | 1980s | 人工编写语法规则 → 不灵活 |
| 统计翻译 | 1990s-2000s | 基于概率统计 → 效果一般 |
| 神经翻译 | 2015+（Seq2Seq + Attention） | 效果大幅提升 |
| 大模型翻译 | 2022+ | GPT 直接翻译，不用专门模型 |

---

## 3.6 ✍️ 文本摘要（Text Summarization）

**定义**：把长文本压缩成简短的摘要，保留核心信息。

| 方式 | 做法 | 类比 |
|------|------|------|
| **抽取式** | 从原文挑最重要的句子组合 | 用荧光笔划重点 |
| **生成式** | 理解原文后用新句子重写 | 读完书用自己的话写摘要 |

---

## 3.7 ❓ 问答系统（Question Answering）

- **抽取式 QA**：从给定文章中找答案片段（如 BERT 的 SQuAD 任务）
- **生成式 QA**：模型自己生成答案，不局限于给定文本（如 ChatGPT）

---

## 3.8 📝 文本生成（Text Generation）

**核心**：给定开头或提示（Prompt），让模型续写。

```
字符级 → 词级 → 句子级 → 篇章级
"我爱"   "我爱北京"  "我爱北京天安门"  一篇完整的文章
```

大模型时代能力：写邮件、写代码、写诗、写故事、角色对话。

---

## 3.9 🔗 关系抽取（Relation Extraction）

**定义**：从文本中识别实体之间的语义关系（构建知识图谱的核心）。

```
输入："苹果公司在1976年由乔布斯创立"
输出：苹果公司 ──创始人──→ 乔布斯
     苹果公司 ──创立于──→ 1976年
```

---

## 3.10 📊 任务难度对比

| 任务 | 难度 | 适合入门？ | 大模型基本解决？ |
|------|:----:|:----------:|:--------------:|
| 文本分类 | ⭐⭐ | ✅ | ✅ |
| NER | ⭐⭐⭐ | ✅ | ✅ |
| 词性标注 | ⭐⭐ | ✅ | ✅ |
| 机器翻译 | ⭐⭐⭐⭐ | ❌ | ✅ |
| 文本摘要 | ⭐⭐⭐⭐ | ❌ | ✅ |
| 问答系统 | ⭐⭐⭐ | ✅ | ✅ |
| 文本生成 | ⭐⭐⭐⭐ | ❌ | ✅ |

> 🔑 **关键理解**：有大模型之后，**一个模型搞定所有任务**，只是通过不同 Prompt 来切换。这是 NLP 领域最革命性的变化。

| **PyTorch** | 深度学习训练框架 |

---

## 4.3 💡 核心 Takeaways

1. **AI ⊃ ML ⊃ DL ⊃ NLP ⊃ LLM**，它们是包含关系，不是并列关系
2. **NLP 的三大范式迭代**：任务专用模型 → 预训练+微调 → Prompt+大模型
3. **技术演进完整链条**：RNN → LSTM → Seq2Seq → **Attention** → **Transformer**
4. **2017 年 Transformer 是分水岭**：之前 RNN 称霸，之后 Attention 为王
5. **GPT 生成，BERT 理解**，现在的趋势是融合统一
6. **大模型之前**：每个 NLP 任务单独训练一个模型；**大模型之后**：一个模型通过不同 Prompt 做所有任务
7. **BIO 标注**是序列标注的核心思想：B=开始，I=内部，O=外部
8. **N-gram** 是统计 NLP 的祖师爷，直到今天大模型里"预测下一个词"依然有它的影子

# 综合自测题

读完一遍后，盖上笔记试着回答这些问题：

<details>
<summary><b>Q1：AI / ML / DL / NLP / LLM 的包含关系是什么？</b></summary>

AI ⊃ ML ⊃ DL ⊃ NLP ⊃ LLM，从大到小依次包含。
</details>

<details>
<summary><b>Q2：为什么语言理解对机器来说是难题？</b></summary>

语言充满歧义（一词多义）、依赖上下文、有创造性，不像图像那样"所见即所得"。
</details>

<details>
<summary><b>Q3：NLP 的三类范式是什么？</b></summary>

① 任务专用模型 → ② 预训练+微调 → ③ Prompt+大模型
</details>

<details>
<summary><b>Q4：N-gram 的 Bigram 和 Trigram 区别是什么？</b></summary>

Bigram 看前 1 个词预测当前词；Trigram 看前 2 个词。Trigram 上下文更多但数据更稀疏。
</details>

<details>
<summary><b>Q5：Bag of Words 最大的缺点是什么？</b></summary>

丢失词序信息——"我打你"和"你打我"表示相同。
</details>

<details>
<summary><b>Q6：为什么 RNN 处理长文本效果不好？</b></summary>

梯度消失问题。文本越长，反向传播梯度连乘越来越小，前面的词就"学不到了"。
</details>

<details>
<summary><b>Q7：BIO 标注的三个字母代表什么？</b></summary>

B = Begin（实体开始位置），I = Inside（实体内部），O = Outside（非实体）。
</details>

<details>
<summary><b>Q8：NER 是做什么的？能识别哪些类型的实体？</b></summary>

从文本中识别出有意义实体，如人名(PER)、地名(LOC)、机构(ORG)、时间(TIME)、金额(MONEY)等。
</details>

<details>
<summary><b>Q9：为什么说 2017 年是 NLP 的分水岭？</b></summary>

Google 发表 "Attention Is All You Need"，提出 Transformer，完全抛弃 RNN，实现并行计算和全局注意力。
</details>

<details>
<summary><b>Q10：Transformer 相比 RNN 最大的两个改进是什么？</b></summary>

① Self-Attention 替代循环 → 可并行计算；② 每个位置直接关注所有位置 → 解决长距离依赖。
</details>

<details>
<summary><b>Q11：GPT 和 BERT 的主要区别？</b></summary>

GPT = 单向（从左到右预测下一个词），适合**生成**；BERT = 双向（遮词预测），适合**理解**。GPT 用 Decoder，BERT 用 Encoder。
</details>

<details>
<summary><b>Q12：抽取式摘要和生成式摘要的区别？</b></summary>

抽取式 = 从原文挑重要句子组合；生成式 = 理解后用自己的话重写。
</details>

<details>
<summary><b>Q13：NLP 技术演进的三条主线是什么？</b></summary>

① 从手工到自动；② 从串行到并行；③ 从单任务到大统一。
</details>
