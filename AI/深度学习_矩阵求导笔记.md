# 📐 深度学习中的矩阵求导

> 🎯 只学深度学习用得上的矩阵求导，不学理论全部

---

## 一、为什么需要矩阵求导？

### 1.1 神经网络中全是矩阵

```
# 一个 Affine 层
Y = X · W + B

X: (N×M)      —— N 条数据，每条 M 个特征
W: (M×K)      —— 权重矩阵
B: (K,)       —— 偏置向量
Y: (N×K)      —— 输出

L = 损失函数（标量）
```

反向传播要对 **W** 和 **B** 求导，这就涉及矩阵求导。

### 1.2 我们的目标

```
已知: ∂L/∂Y  (下游传过来的梯度)
求:   ∂L/∂X  (继续往前传)
      ∂L/∂W  (更新权重)
      ∂L/∂B  (更新偏置)
```

---

## 二、核心概念：形状匹配原则

> **矩阵求导最重要的原则：求导结果的形状 = 被求导变量的形状**

```
例子：
L 对向量 x 求导 → 结果形状 = x 的形状 (3,)
L 对矩阵 W 求导 → 结果形状 = W 的形状 (4×2)
```

这个原则是**验证答案是否正确的最强工具**。公式记不清没关系，形状对了就大概率没错。

---

## 三、标量对向量的求导

### 3.1 基本定义

```
L 是标量（损失值）
x 是向量  [x₁, x₂, ..., xₙ]

∇L = ∂L/∂x = [∂L/∂x₁, ∂L/∂x₂, ..., ∂L/∂xₙ]

结果形状 = x 的形状
```

### 3.2 三个必背公式

**公式 1：线性项求导**

```python
若 y = aᵀx = a₁x₁ + a₂x₂ + ... + aₙxₙ

则 ∂y/∂x = a
```

**公式 2：二次型求导**

```python
若 y = xᵀAx

则 ∂y/∂x = (A + Aᵀ)x

如果 A 是对称矩阵：∂y/∂x = 2Ax
```

**公式 3：简单线性变换**

```python
若 y = Ax   (A 是矩阵, x 是向量)

则 ∂y/∂x = Aᵀ    ← 重要！
```

## 四、深度学习最常用的：Y = XW 的求导

### 4.1 场景

```python
Y = X · W

X: (N×M)  输入
W: (M×K)  权重
Y: (N×K)  输出
```

### 4.2 两个核心公式

```python
已知: dout = ∂L/∂Y  (N×K)

∂L/∂X = dout · Wᵀ    # 右乘 W 转置
∂L/∂W = Xᵀ · dout    # 左乘 X 转置
```

### 4.3 用形状验证

```python
# 验证 ∂L/∂X = dout · Wᵀ
dout: (N×K)
Wᵀ:   (K×M)     ← W 原来是 (M×K)

乘法: (N×K) · (K×M) = (N×M)  ← 和 X 的形状一致 ✅


# 验证 ∂L/∂W = Xᵀ · dout
Xᵀ:   (M×N)
dout: (N×K)

乘法: (M×N) · (N×K) = (M×K)  ← 和 W 的形状一致 ✅
```

### 4.4 记忆口诀

> **X 的梯度：右乘 W 转置**  
> **W 的梯度：X 转置左乘**

## 五、广播加法（Y = X + B）的求导

### 5.1 场景

```python
B 是向量 (K,)
Y = XW + B    # 广播：B 自动扩展为 (N×K)
```

### 5.2 求导

```python
∂L/∂B = np.sum(dout, axis=0)

# dout: (N×K)
# sum(axis=0) → (K,)  ← 和 B 的形状一致 ✅
```

### 5.3 直觉理解

B 广播给了 N 条数据共享，所以反向梯度要**把 N 条数据的影响累加回来**：

```
B 对 Y 的影响：
B[0] → Y[0][0], Y[1][0], Y[2][0], ..., Y[N-1][0]  (N个)

所以 ∂L/∂B[0] = sum(∂L/∂Y[0][0], ∂L/∂Y[1][0], ..., ∂L/∂Y[N-1][0])
```

## 六、逐元素运算的求导

### 6.1 场景

```python
Y = ReLU(X)     # 逐元素操作
Y = Sigmoid(X)  # 逐元素操作
Y = X + 1       # 逐元素操作
```

### 6.2 规则

> **逐元素运算的导数 = dout × 局部导数（逐元素相乘）**

```python
# ReLU
∂L/∂X = dout * (X > 0 ? 1 : 0)   # 元素级 mask

# Sigmoid
∂L/∂X = dout * Y * (1 - Y)       # 元素级乘法

# X + 1
∂L/∂X = dout * 1 = dout          # 元素级不变
```

> 这里的 × 是 **Hadamard 积**（逐元素相乘），不是矩阵乘法。

## 七、常见运算速查表

### 7.1 形状速查

| 变量 | 形状 | 含义 |
|------|------|------|
| 标量 | () | 损失函数 L |
| 向量 | (n,) | 偏置 B、单个样本的特征 |
| 矩阵 | (m×n) | 权重 W、批量数据 X |

### 7.2 求导公式速查

| 前向运算 | 形状 | ∂L/∂(自变量) = ? | 验证形状 |
|---------|------|-----------------|---------|
| Y = X | (N×M) | dout | (N×M) ✅ |
| Y = aX | (N×M) | a × dout | (N×M) ✅ |
| Y = X + B | (N×K) | dB = sum(dout, axis=0) | (K,) ✅ |
| Y = X · W | (N×K) | dX = dout · Wᵀ | (N×M) ✅ |
| Y = X · W | (N×K) | dW = Xᵀ · dout | (M×K) ✅ |
| Y = ReLU(X) | (N×M) | dX = mask × dout | (N×M) ✅ |
| Y = X⊙Z | (N×M) | dX = dout ⊙ Z (逐元素乘) | (N×M) ✅ |

### 7.3 记忆口诀汇总

```
标量对向量求导：形状相同
Y = AX 求导：∂Y/∂X = Aᵀ
Y = XW 求 dX：右乘 Wᵀ
Y = XW 求 dW：Xᵀ 左乘
广播加法求 dB：按行求和
逐元素运算：dout × 局部导数（逐元素）
```

## 八、完整推导示例：Affine 层

### 8.1 前向

```python
Y = X · W + B
```

### 8.2 反向传播推导

**第 1 步：加法节点**

```python
Y = XW + B = Z + B
其中 Z = XW

加法节点：梯度原样传递
dZ = dout    # Z 的梯度
dB = np.sum(dout, axis=0)  # B 广播，按行求和
```

**第 2 步：矩阵乘法节点**

```python
Z = X · W

这里把 X 和 W 都看作"输入"，分别求导：

对 X 求导（作为自变量）：
  ∂L/∂X = dZ · Wᵀ = dout · Wᵀ
  形状：(N×K)·(K×M) = (N×M) ✅

对 W 求导（作为自变量）：
  ∂L/∂W = Xᵀ · dZ = Xᵀ · dout
  形状：(M×N)·(N×K) = (M×K) ✅
```

### 8.3 与标量情况对比

```
标量版本：    矩阵版本：
y = x · w     Y = X · W

∂y/∂x = w     ∂L/∂X = dout · Wᵀ
∂y/∂w = x     ∂L/∂W = Xᵀ · dout
```

矩阵版本就是在标量版本基础上，多了**转置**和**保持乘法顺序**。

## 九、什么时候需要矩阵求导？

| 情况 | 是否需要矩阵求导 | 例子 |
|------|---------------|------|
| 损失函数对输出求导 | 不需要（直接的链式法则） | ∂L/∂Y |
| 对无参数层求导 | 不需要（直接用已有规则） | ReLU、Sigmoid |
| **对有参数层求导** | **需要** | Affine: ∂L/∂W, ∂L/∂B |
| 自定义层 | 需要 | 自己写新层时 |

> **结论**：学完本节内容，你就能处理神经网络中 95% 的矩阵求导场景了。🎯

### 练习 2：数值验证

```python
import numpy as np

# 给定数据
X = np.array([[1, 2], [3, 4]])
W = np.array([[0.5, 0.1], [0.2, 0.3]])
B = np.array([0.1, 0.2])
dout = np.array([[1, 2], [3, 4]])

# 计算反向传播梯度
# 用本节学到的公式算出 dX, dW, dB
# 再用数值微分验证
```

<details>
<summary>点击查看答案</summary>

```python
# 反向传播
Y = X @ W + B
dX = dout @ W.T    # (2,2) @ (2,2) = (2,2)
dW = X.T @ dout    # (2,2) @ (2,2) = (2,2)
dB = np.sum(dout, axis=0)  # (2,)

# 数值微分验证 dW
h = 1e-5
dW_num = np.zeros_like(W)
for i in range(W.shape[0]):
    for j in range(W.shape[1]):
        old = W[i, j]
        W[i, j] = old + h
        y1 = np.sum(dout * (X @ W + B))
        W[i, j] = old - h
        y2 = np.sum(dout * (X @ W + B))
        W[i, j] = old
        dW_num[i, j] = (y1 - y2) / (2 * h)

print("dW 最大误差:", np.max(np.abs(dW_num - dW)))
# 应该远小于 1e-4
```

</details>
