# 第一讲：用生活例子解释什么是期权

## 一、两个生活故事带你理解期权

### 故事1：买房——看涨期权（Call Option）

**场景：**
- 你看上了一套 **100万** 的房子，但手头钱不够
- 你担心 **1年后** 房价上涨买不起
- 于是你和房东 **老王** 商量，先付 **10万** 定金，锁定1年后用 **100万** 买这套房

**关键点：**
- 你付了 10万 之后，**有权**（但不是义务）在1年后以100万的价格买下房子
- 如果房价涨到 120万，你**可以行使权利**，用100万买到价值120万的房子
- 如果房价跌到 80万，你**可以选择不行使权利**，直接去市场上买更便宜的房子
- 如果不行使权利，你交的10万定金**不会退还**

### 故事2：卖车——看跌期权（Put Option）

**场景：**
- 你有一辆车，担心 **1个月内** 车子贬值
- 你找到朋友 **老李**，付 **2000元** 作为补偿
- 老李答应：1个月后无论车价多少，他都用 **3万元** 买你的车

**关键点：**
- 你付了2000元，获得了**在1个月后以3万元卖车给老李的权利**
- 如果车价跌到2万，你**可以行使权利**，以3万把车卖给老李
- 如果车价涨到4万，你**可以不行使权利**，直接把车卖给市场上出价更高的人
- 这就像买了一份**保险**——花2000元给自己一个保底价

---

## 二、期权的本质

> **期权的本质 = 为一个"选择权"而签订的合约**

- 合约上有两方：**买方** 和 **卖方**
- 买方支付一笔钱（权利金），获得一个**选择权**
- 卖方收取这笔钱，承担**必须履行的义务**

---

## 三、期权的两种基本类型

| 中文名称 | 英文名称 | 本质 | 生活比喻 |
|---------|---------|------|---------|
| **看涨期权** | **Call Option** | 给买方**买入**资产的权利 | 故事1：用固定价格买房 |
| **看跌期权** | **Put Option** | 给买方**卖出**资产的权利 | 故事2：用固定价格卖车 |

> 简单记：**Call = 买的选择权，Put = 卖的选择权**

---

## 四、期权的三大核心要素

每份期权合约都有三个必不可少的要素：

### 1. 到期日（Expiration Date）
- 期权合约的**最后一天**
- 过了这一天，期权就作废
- 例如：买房故事中的"1年后"，卖车故事中的"1个月后"

### 2. 行权价（Strike Price）
- 合约中**提前锁定好的交易价格**
- 例如：买房故事中的100万，卖车故事中的3万

### 3. 权利金（Premium）
- 买方为获得选择权而支付的**价格 / 保费**
- 例如：买房故事中的10万，卖车故事中的2000元
- 无论是否行权，权利金**概不退还**

---

## 五、买方 vs 卖方的根本区别

| 角色 | 权利与义务 | 风险 |
|-----|-----------|------|
| **买方** | 拥有**权利**，可以行使，也可以不行使 | 最大亏损 = 权利金（有限） |
| **卖方** | 承担**义务**，对方行权时必须履行 | 风险较大（理论无限） |

---

## 六、现实中的期权长什么样？

### 苹果公司 Call Option 示例
- 标的资产（正股）：**苹果公司股票（AAPL）**
- 到期日：**2021年8月20日**（1个月后）
- 行权价：**150美元**
- 权利金：**3.9美元**（实际交易中1张期权 = 3.9 × 100 = 390美元）
- 含义：在8月20日或之前，有权用150美元/股的价格买入苹果股票

### SPY（标普500 ETF）Put Option 示例
- 标的资产（正股）：**SPY（标普500指数ETF）**
- 到期日：**2021年8月20日**
- 行权价：**410美元**
- 权利金：**1.35美元**
- 含义：在8月20日或之前，有权用410美元/股的价格卖出SPY

---

## 七、第一讲小结

| 概念 | 一句话记住 |
|------|-----------|
| **期权** | 为一个选择权而签订的合约 |
| **Call（看涨期权）** | 给你买入资产的权利 |
| **Put（看跌期权）** | 给你卖出资产的权利 |
| **到期日** | 期权合约的截止日 |
| **行权价** | 合约锁定的交易价格 |
| **权利金** | 买方付给卖方的"保费" |
| **正股（标的资产）** | 期权合约对应的股票或ETF |
| **买方** | 有权利，风险有限 |
| **卖方** | 有义务，风险较大 |

# 第二讲：期权跟正股股价的关系

## 一、核心要点

> **期权只有 Call 和 Put 两种，没有其他的了。**
> **影响期权价格最重要的因素 = 正股价格的变动。**

---

## 二、Call 和 Put 分别代表对股价的两种看法

### Call Option（看涨期权）

- **买 Call = 看涨股票**
- 当你买入Call后，你**希望股价上涨**
- 股价涨得越高，你的Call就越值钱

**原理（回到买房故事）：**
你花10万买了一个1年后用100万买房的权利。买了这个权利后，你当然希望房价涨——房子涨到120万，你能用100万买到；涨到150万，你更能用100万买到。赚的差价越大，你的这个"权利"就越值钱。

**对应到股票：**
你买了一张行权价150美元的苹果Call Option。如果苹果涨到200美元，你可以用150美元买入苹果，转手就能赚50美元差价。所以股价越高，Call越值钱。

---

### Put Option（看跌期权）

- **买 Put = 看跌股票**
- 当你买入Put后，你**希望股价下跌**
- 股价跌得越多，你的Put就越值钱

**原理（回到卖车故事）：**
你花2000元买了一个1个月后以3万卖车的权利。如果车价跌到2万，你就能行使权利，用3万把车卖给老李。车价跌得越低，这个"保险"的价值就越大。

**对应到股票：**
你买了一张行权价410美元的SPY Put Option。如果SPY跌到390美元，你可以以390美元买入SPY，然后立刻行使权利以410美元卖出，赚20美元差价。所以SPY跌得越多，Put越值钱。

---

## 三、买方的完整逻辑

### 买 Call（看涨期权）的盈亏逻辑

```
股价 → 上涨   → Call价值↑ → 买方赚钱
股价 → 下跌   → Call价值↓ → 买方亏钱（最多亏完权利金）
股价 → 不动   → Call价值归零 → 买方亏完权利金
```

### 买 Put（看跌期权）的盈亏逻辑

```
股价 → 下跌   → Put价值↑  → 买方赚钱
股价 → 上涨   → Put价值↓  → 买方亏钱（最多亏完权利金）
股价 → 不动   → Put价值归零 → 买方亏完权利金
```

---

## 四、卖方：与买方完全相反

期权是一个**零和游戏**——一方得到的，就是另一方失去的。

| 操作 | 对股价的看法 | 赚钱条件 | 最大收益 | 最大亏损 |
|------|------------|---------|---------|---------|
| **买 Call** | 看涨 | 股价上涨 | 理论无限 | 权利金 |
| **卖 Call** | 看跌 | 股价不涨 | 权利金 | 理论无限 |
| **买 Put** | 看跌 | 股价下跌 | 行权价-权利金 | 权利金 |
| **卖 Put** | 看涨 | 股价不跌 | 权利金 | 行权价-权利金 |

### 例子说明

**卖 Call（看跌）：**
卖苹果150行权价的Call的人，希望苹果股价**低于150美元**。因为没人会花150去买入市价更低的股票，所以买方不会行权，Call变废纸，卖方安心收权利金。

**卖 Put（看涨）：**
卖SPY 410行权价的Put的人，希望SPY股价**高于410美元**。因为没人会以410卖出市价更高的股票，所以Put变废纸，卖方安心收权利金。

---

## 五、保护性看跌期权（Protective Put）

当你**持有正股 + 买入Put**，这个组合叫做 **Protective Put**。

- 买Put相当于是给你的股票买了一份**下跌保险**
- 股价跌了，Put能弥补损失
- 股价涨了，你只是白花了一点"保费"

> 这个策略我们先留个印象，后面学到策略时会详细展开。

---

## 六、第二讲小结

| 操作 | 看涨/看跌 | 希望股价 |
|------|----------|---------|
| **买 Call** | 看涨 | 上涨 ↑ |
| **卖 Call** | 看跌 | 下跌或不涨 ↓ |
| **买 Put** | 看跌 | 下跌 ↓ |
| **卖 Put** | 看涨 | 上涨或不跌 ↑ |

# 第三讲：IB交易平台实操指南

## 一、为什么选择IB（Interactive Brokers）

IB的几大优势：
- 覆盖市场广、产品全
- 佣金低、融资成本低
- 期权功能齐全、成交价合理
- 全球用户都能使用

> 如果你用其他券商也不用担心，多数券商期权交易页面的逻辑**大同小异**。

---

## 二、期权交易的四个步骤

> **不管期权策略有多复杂，都逃不开这四步：**

```
Step 1 → 选择正股
Step 2 → 选择期权策略
Step 3 → 选择到期日
Step 4 → 选择行权价
```

---

## 三、IB期权交易页面详解

### 第一步：选择正股
- 在左上角输入股票的**Ticker（代码）**，例如 AAPL（苹果）
- 新手建议选择**自己熟悉且交易量大**的正股
- 苹果是所有个股中期权交易量最大的股票

### 第二步：查看报价
- 页面最上面一行显示**正股的当前股价**
- 例如：苹果股价大概是140美元左右

### 第三步：选择到期日
- 显示不同到期日，多数公司期权在**每周五**到期
- 少数ETF（如SPY）周一、周三、周五都有
- 选择后，下方会显示该到期日的**期权链（Option Chain）**

### 第四步：看懂期权链

期权链的布局：

```
  Call（看涨期权）  |  行权价  |  Put（看跌期权）
   左边全部         |  中间    |   右边全部
```

- 行权价从上到下由**低到高**排列
- 左侧 = 所有Call的信息
- 右侧 = 所有Put的信息

---

## 四、需要重点关注的数据

### 1. 报价（Bid / Ask）
- **Bid** = 买方的出价
- **Ask** = 卖方的要价
- 与股票报价逻辑一样

**一个重要的坑：**
> 期权报价显示的是**一张（per share）**的价格
> 但实际交易中，**1张期权合约 = 100股**
>
> 例如：报价0.14美元的期权，实际买入需要花 0.14 × 100 = **14美元**

### 2. 交易量（Volume）
- 代表这张期权的**流动性**
- **交易量越大** → 流动性越好 → 成交价更优 → 少被做市商"割韭菜"
- 通常**行权价在股价附近**的期权，交易量最大

### 3. 隐含波动率（IV - Implied Volatility）
- 右上角的百分比数字，例如 24.5%
- **IV越高 → 期权越贵**
- 之后会花很多时间详细讲这个指标

---

## 五、如何在IB下单

1. 选择：10月15日到期

# 第四讲：期权的买方和卖方

## 一、两个容易混淆的概念

### 误区1：卖期权 ≠ 先持有期权才能卖

- 卖股票：你得**先买入**股票才能卖出
- 卖期权：你**不需要持有期权**就可以直接卖
- 这跟股票的交易逻辑完全不同

### 误区2：卖期权 ≠ 卖空

| 概念 | 含义 |
|------|------|
| **卖空（Short Selling）** | 借入股票卖出，等股价跌了再买回来还回去 |
| **卖期权（Sell Option）** | 作为期权的**卖方**，收权利金，承担义务 |

> 这两个是完全不同的概念，不要混淆。

---

## 二、看穿期权的买卖本质

> **不要把期权当成资产买卖，而要把它看作一种"服务"**

- **卖方** = 服务的**提供方**，收取服务费（权利金）
- **买方** = 服务的**接受方**，支付服务费，期待服务带来的价值超过服务费本身

---

## 三、买方 vs 卖方的三个对比维度

### 维度一：权利金的意义不同

| 角色 | 对权利金的看法 |
|------|--------------|
| **卖方** | 收取权利金 = 提供服务的**好处费** |
| **买方** | 支付权利金 = 购买选择权的**成本**，期待未来能产生超值的回报 |

### 维度二：对股价方向的判断完全相反

> 买方的意愿 = 卖方的不意愿

| 操作 | 对股价看法 | 希望股价 |
|------|-----------|---------|
| **买 Call** | 看涨 | 涨 ↑ |
| **卖 Call** | 不看涨（≠看跌） | 不涨就行 |
| **买 Put** | 看跌 | 跌 ↓ |
| **卖 Put** | 不看跌（≠看涨） | 不跌就行 |

> 注意这里用的是"不看涨"、"不看跌"，而不是"看跌"、"看涨"——卖方只要让买方的意愿达不成，就能赚钱，并不要求股价朝反方向大幅移动。

### 维度三：收益风险比完全对立

| 角色 | 最大收益 | 最大亏损 |
|------|---------|---------|
| **买方** | 理论**无限**（动辄翻几倍） | **有限**（最多亏完权利金） |
| **卖方** | **有限**（最多收完全部权利金） | 理论**无限** |

---

## 四、买方收益风险特征详解

### 买方的优势——亏损有限，收益无限

```
最大亏损 = 你买期权花的全部权利金
最大收益 = 理论上没有上限（股价能涨多高，你就能赚多少）
```

**例子：**
花3.9美元买一张苹果150行权价的Call——
- 最坏情况：苹果跌到0，你最多亏3.9美元
- 最好情况：苹果涨到200、300、甚至更高，收益没有上限

### 买方的劣势——胜率低

> 大多数期权到期时都会变成废纸，所以买方常常亏钱。

---

## 五、卖方收益风险特征详解

### 卖方的优势——胜率高

- 卖方只需要"股价不涨"或"股价不跌"就能赚钱
- 条件比买方更宽松
- 长期来看，卖方胜率远高于买方

### 卖方的劣势——亏损无限

```
最大收益 = 全部的权利金（有限）
最大亏损 = 理论上没有上限
```

---

## 六、一个灵魂问题：既然卖方亏损无限，为什么还有人做卖方？

> 自由市场下，不会有持续吃亏的一方。所有吃亏和占便宜都反映在了**价格（权利金）**上了。

简单说：
- 买方虽然亏损有限、收益无限，但**胜率低**，大多数时候亏钱
- 卖方虽然亏损无限、收益有限，但**胜率高**，大多数时候赚钱
- 权利金的定价已经考虑了这种不对称性

---

## 七、第四讲小结

| 对比维度 | 买方 | 卖方 |
|---------|------|------|
| 角色 | 服务的接受方 | 服务的提供方 |
| 权利金 | 付出的成本 | 收取的好处费 |
| 对股价看法 | 看涨或看跌 | 不看涨或不看跌 |
| 最大收益 | 理论无限 | 有限（权利金） |
| 最大亏损 | 有限（权利金） | 理论无限 |
| 胜率 | 低 | 高 |

---

# 第五讲：什么是ITM、ATM、OTM期权

## 一、核心概念

> 根据**行权价**与**当前股价**的关系，所有期权分为三类：

| 英文 | 缩写 | 中文 |
|------|------|------|
| **In The Money** | **ITM** | **价内期权** |
| **At The Money** | **ATM** | **平价期权** |
| **Out of The Money** | **OTM** | **价外期权** |

这是一套贯穿整个期权交易生涯的核心分类，做任何期权操作都离不开它。

---

## 二、ITM（价内期权）—— 行权后有收益

### 什么是ITM？

> 如果买方**现在立即行权**能够获得收益，这张期权就是 **ITM（价内期权）**。

### Call 的 ITM 判断

对于 **Call Option**：
- **行权价 < 当前股价** → ITM
- 因为你可以用**更低的价格**买入**更贵的股票**

**生活例子（买菜）：**
你有权利花 **5块钱** 买下价值 **10块钱** 的白菜 → 当然要行权！赚了5块差价。

**实际案例（苹果期权链）：**
- 苹果当前股价：**146.87美元**
- 行权价140美元的Call → ITM
- 因为你可以花140美元买入现价146.87美元的股票，立刻赚 **6.87美元**

### Put 的 ITM 判断

对于 **Put Option**（刚好相反）：
- **行权价 > 当前股价** → ITM
- 因为你可以用**更高的价格**卖出**更便宜的股票**

**生活例子（卖菜）：**
白菜值10块钱，你有权利以**100块钱**把白菜卖给隔壁超市 → 当然要行权！赚了90块。

**实际案例（苹果期权链）：**
- 苹果当前股价：**146.87美元**
- 行权价150美元的Put → ITM
- 因为你可以以150美元卖出只值146.87美元的股票，立刻赚 **3.13美元**

---

## 三、OTM（价外期权）—— 行权后无收益

### 什么是OTM？

> 如果买方**现在立即行权**无法获得收益（甚至亏损），这张期权就是 **OTM（价外期权）**。

### Call 的 OTM 判断

对于 **Call Option**：
- **行权价 > 当前股价** → OTM
- 因为没人愿意用**比市场价更高的价格**买入股票

**生活例子：**
白菜现价10块钱，你有权利**花100块钱**买这棵白菜 → 你会用吗？肯定不会！

**实际案例（苹果期权链）：**
- 苹果当前股价：**146.87美元**
- 行权价150美元的Call → OTM
- 因为你要花150美元买入只值146.87美元的股票，亏本买卖

### Put 的 OTM 判断

对于 **Put Option**（刚好相反）：
- **行权价 < 当前股价** → OTM
- 因为没人愿意用**比市场价更低的价格**卖出股票

**实际案例（苹果期权链）：**
- 苹果当前股价：**146.87美元**
- 行权价140美元的Put → OTM
- 因为你要以140美元卖出值146.87美元的股票，亏本买卖

---

## 四、ATM（平价期权）—— 行权价 ≈ 股价

### 什么是ATM？

> 行权价**刚好等于**（或非常接近）当前股价的期权，称为 **ATM（平价期权）**。

### 特点
- 行权与否都没有收益或亏损
- 现实中很难出现严格等于的情况（做市商不会做146.87美元的期权）
- 一般把行权价**最接近股价**的期权称为ATM

**实例：**
苹果股价146.87美元，那么行权价**146美元**和**147美元**的期权都可以称为ATM。

---

## 五、如何在IB交易系统里快速识别

在IB的期权链页面中：
- **蓝色区域** = ITM（价内期权）
- **黑色区域** = OTM（价外期权）
- 蓝色和黑色之间变化的边界就是股价所在的位置

> 只看颜色变化，不看股价数字，你就能知道当前股价的范围。

---

## 六、第五讲小结

### 判断速查表

| 期权类型 | Call的条件 | Put的条件 |
|---------|-----------|----------|
| **ITM**（价内） | 行权价 **<** 股价 | 行权价 **>** 股价 |
| **ATM**（平价） | 行权价 **≈** 股价 | 行权价 **≈** 股价 |
| **OTM**（价外） | 行权价 **>** 股价 | 行权价 **<** 股价 |

### 一句话口诀

```
Call：ITM = 行权价低（赚差价），OTM = 行权价高（亏差价）
Put：ITM = 行权价高（赚差价），OTM = 行权价低（亏差价）
```

### 为什么这很重要？

不同类别的期权有着完全不同的特性和适用策略：
- 有些策略**只适合用OTM**期权来做
- 比如赌方向的策略**比较适合用ATM**期权来做
- 后面的课程会详细介绍

---

# 第六讲：期权的价格构成——时间价值与内在价值

## 一、期权的价格可以拆分为两部分

> **期权价格 = 内在价值（Intrinsic Value）+ 时间价值（Time Value）**

| 组成部分 | 英文 | 含义 |
|---------|------|------|
| **内在价值** | Intrinsic Value | 当前行权所能获得的价值——**实打实的差价** |
| **时间价值** | Time Value | 除去内在价值后剩余的部分——**等待的"时间成本"** |

---

## 二、从生活例子理解

### 买房谈判的完整故事

**场景：**
你相中了老刘手里**现在值120万**的房子，想签一个一年后用**100万**买的Call合约。

**老刘会怎么想？**
> "现在就能卖120万，你让我一年后只卖100万，凭什么？"

**你要说服老刘，需要补偿他两笔钱：**

1. **补偿差价**：现价120万 - 未来交割价100万 = **20万**
   - 这20万就是这张Call期权的**内在价值**
   - 不让老刘亏在差价上

2. **补偿时间成本**：老刘要等你一年，这段时间他不能把房子卖给别人 = **5万**
   - 这5万就是这张Call期权的**时间价值**
   - 让人家等一年需要额外补偿

**结论：你需要付给老刘 20万 + 5万 = 25万**

这个25万就是这张Call Option的价格。

---

## 三、应用到实际股票期权

### 例子1：ITM Call 的价格拆解

**数据：**
- 苹果当前股价：**153美元**
- 行权价150美元的Call报价：**4.55美元**
- 这是一张**ITM Call**（行权价 < 股价）

**内在价值计算：**
```
内在价值 = 当前股价 - 行权价
         = 153 - 150
         = 3.00 美元
```
> 内在价值 = 现在行权后马上转手卖出的差价

**时间价值计算：**
```
时间价值 = 期权价格 - 内在价值
         = 4.55 - 3.00
         = 1.55 美元
```
> 时间价值 = 让卖方等你到到期的"等待补偿"

### 例子2：OTM Call 的价格拆解

**数据：**
- 苹果当前股价：**153美元**
- 行权价155美元的Call报价：**1.9美元**
- 这是一张**OTM Call**（行权价 > 股价）

**内在价值：**
```
内在价值 = 0 美元
```
> 因为现在行权只会亏损（以155买入值153的股票），所以内在价值为0。

**时间价值：**
```
时间价值 = 1.9 - 0 = 1.9 美元
```
> **所有价值都是时间价值！**

---

## 四、核心规律

### ITM（价内期权）
| 组成 | 值多少 |
|------|-------|
| **内在价值** | **> 0**（股价 - 行权价） |
| **时间价值** | **> 0**（期权价格 - 内在价值） |

### OTM（价外期权）
| 组成 | 值多少 |
|------|-------|
| **内在价值** | **= 0**（行权不会有收益） |
| **时间价值** | **= 全部期权价格** |

### ATM（平价期权）
| 组成 | 值多少 |
|------|-------|
| **内在价值** | **≈ 0**（行权基本无收益） |
| **时间价值** | **≈ 全部期权价格**（而且ATM的时间价值通常最大） |

---

## 五、为什么要区分内在价值和时间价值？

> 在交易期权时，**大部分情况下我们更加看重时间价值**，而不是内在价值。

- **内在价值**很好理解：就是股价减去行权价的差价
- **时间价值**更抽象：代表了未来的不确定性、时间的等待成本、波动预期等
- 下一讲会重点讨论**时间价值的性质和特点**

### 给初学者留一个思考作业

在刚才苹果股价153美元的例子中：

| 标的 | 行权价 | 类型 | 期权价格 | 内在价值 | 时间价值 |
|------|--------|------|---------|---------|---------|
| AAPL Call | 150 | ITM | 4.55 | 3.00 | 1.55 |
| AAPL Call | 155 | OTM | 1.90 | 0 | 1.90 |
| AAPL **Put** | 150 | ❓ | ❓ | ❓ | ❓ |
| AAPL **Put** | 155 | ❓ | ❓ | ❓ | ❓ |

> 你可以试着自己思考：对于Put来说，内在价值和时间价值分别是多少？
> （提示：先判断是ITM还是OTM，再套用上面的公式）

---

## 六、第六讲小结

| 概念 | 定义 | 公式 |
|------|------|------|
| **期权价格** | 期权的总报价 | 内在价值 + 时间价值 |
| **内在价值** | 立即行权能获得的收益 | Call：股价 - 行权价（>0时） |
| **时间价值** | 期权总价减去内在价值 | 期权价格 - 内在价值 |
| **ITM的内在价值** | > 0 | 股价与行权价的差额 |
| **OTM的内在价值** | = 0 | 全部都是时间价值 |
| **ATM的内在价值** | ≈ 0 | 几乎全部是时间价值 |

# 第七讲：时间价值的特性

## 一、回顾：期权价格的两个组成部分

```
期权价格 = 内在价值（Intrinsic Value）+ 时间价值（Time Value）
```

- **内在价值**：立即行权能获得的差价收益——简单直接
- **时间价值**：剩余部分——代表了"未来的可能性"和"等待的成本"

第六讲我们学会了拆分，这一讲我们来深入理解 **时间价值** 的规律和特性。

---

## 二、时间价值的两个核心规律

### 规律一：到期时间越长 → 时间价值越高

同一张期权，到期时间越长，时间价值就越高。

| 对比 | 一年期期权 | 半年期期权 |
|------|-----------|-----------|
| 时间价值 | **高** | **低** |
| 原因 | 买方有更多时间等待股价变化，卖方承担更长的风险 | 时间短，变数少 |

> 反过来理解：一张一年到期的期权，过半年后（即使股价没变），它的价值也会下降——这就是 **时间价值衰减**。

### 规律二：越靠近ATM → 时间价值越高

在同一到期日中（同一张图里）：
- **ATM（平价）期权的时间价值最高**
- 无论是ITM还是OTM方向，离ATM越远，时间价值越小

```
时间价值大小排列（同一到期日）：
    
    高 ←—— ATM ——→ 高
         ↗        ↖
    OTM区域      ITM区域
    越远越低     越远越低
```

---

## 三、为什么OTM越远，时间价值越低？

**核心原因：赚钱的概率越来越小**

OTM到期权到现在行权是没收益的，它之所以还有价值，是因为到期前**有可能变成ITM**。

- 如果OTM的幅度很小（比如行权价150，股价147）→ 股价稍微一涨就能变成ITM → **概率大，时间价值高**
- 如果OTM的幅度很大（比如行权价180，股价147）→ 股价需要涨22%以上才能变成ITM → **概率小，时间价值低**

**用苹果实例看：**
- 苹果股价147美元，半年后到期的期权
- 行权价 **180美元** 的Call → OTM幅度22% → 仅仅值 **1.82美元**（时间价值很低）
- 行权价 **150美元** 的Call → 接近ATM → 高达 **8.95美元**（时间价值很高）

---

## 四、为什么ITM越远，时间价值也越低？

这背后的原因稍微复杂一点，但我们可以这样理解：

**本质原因：风险和收益的比例关系**

买ITM Call本质上也是在赌股价上涨。我们拿两张ITM Call来对比：

| 对比 | 行权价145的Call（浅ITM） | 行权价120的Call（深ITM） |
|------|------------------------|------------------------|
| 内在价值 | **2美元** | **27美元** |
| 如果股价涨到150 | 内在价值变成5美元，**赚3美元** | 内在价值变成30美元，**赚3美元** |
| 潜在收益 | **3美元** | **3美元** |
| 你冒的风险 | **2美元**（内在价值成本） | **27美元**（内在价值成本） |

> 两者的潜在收益都一样（都是3美元），但承担的风险完全不同。

人们都喜欢**用更小的风险去博取同样的收益**，因此他们愿意为"降低风险"付出额外的成本——这个成本就是**时间价值**。

所以：
- **浅ITM**：内在价值成本低，风险小，人们愿意为它付更多时间价值
- **深ITM**：内在价值成本高，风险已经被内在价值"吃掉"了，时间价值反而低

---

## 五、第七讲小结

| 规律 | 内容 | 实际意义 |
|------|------|---------|
| **规律一** | 到期时间越长，时间价值越高 | 远期期权更贵，近期期权更便宜 |
| **规律二** | 同一到期日，ATM时间价值最高，越远越低 | 做交易时选什么行权价，直接影响你的成本和时间损耗 |

> **如果你觉得背后的原理云里雾里也没关系，先记住这两个结论，就足够你轻松上手期权了。** 这些原理随着你对期权的理解加深，会迎刃而解。

# 第八讲：时间价值的衰减

## 一、用赌球例子理解时间衰减

**场景：**
你和朋友小明赌一场足球赛，甲队对乙队。

- 根据历史数据，甲队平均每场进1个球
- 你赌甲队**进球多**，小明赌甲队**进球少**
- 约定：甲队每进1个球，小明给你100元
- 但你要先给小明 **100元** 作为参与对赌的"入场费"

**比赛开始前：**
这张赌约价值 **100元**（你付的入场费）

**比赛进行中——价值变化：**

| 时间点 | 甲队进球情况 | 赌约价值变化 | 原因 |
|--------|------------|------------|------|
| 上半场结束 | 0进球 | 价值降到 ~50元 | 甲队进球的概率降低了 |
| 还剩1分钟 | 还是0进球 | 价值接近 **0元** | 甲队基本不可能进球了 |
| 比赛结束 | 0进球 | 价值 = **0元** | 确定输了，小明拿走100元 |

> 整个过程：这张赌约的价值，随着时间流逝而**不断减少**，因为甲队还能赚钱的概率在一点点降低。

---

## 二、期权的时间衰减同样如此

> **期权的赌约 = 赌股票涨跌**
> - 买 Call = 赌 **涨**
> - 买 Put = 赌 **跌**

把赌球的时间线换成期权：

- 距离到期日越远 → 股价还有大把时间变化 → 期权的时间价值**高**
- 距离到期日越近 → 股价变化可能性越来越低 → 期权的时间价值**低**
- 到期日当天 → 再也没有变化可能 → **时间价值 = 0**

这个特性就叫 **时间价值的衰减（Time Decay）**，也叫 **时间损耗（Theta）**。

> 一句话：**时间是买方的敌人，是卖方的朋友。**

---

## 三、时间损耗到底有多快？（实际数据）

以苹果股价150美元左右的 **ATM Put** 为例，观察不同到期日的时间价值：

| 到期日 | 时间价值 | 说明 |
|-------|---------|------|
| 12月到期 | **8.50美元** | 时间还有好几个月 |
| 11月到期 | **7.45美元** | 过了一个月，损耗了1.05美元 |
| ... | 逐月递减 | ... |
| 到期日 | **0美元** | 全部归零 |

> 换句话说，即使股价完全不动，期权的价格也会因为时间流逝而**自动下跌**。

---

## 四、时间衰减曲线——关键的时间节点

时间价值在整个期权生命周期中的衰减**不是匀速**的，而是**加速**的：

```
时间价值
  ↑
  |                                   
  |                                  ■ 离到期还有7个月
  |                                ■  缓慢下降
  |                              ■
  |                            ■
  |                          ■
  |                        ■
  |                      ■
  |                    ■              ← 离到期约3个月，加速开始
  |                  ■
  |                ■
  |              ■
  |            ■                    ← 离到期约1个月，急剧下跌
  |          ■
  |        ■
  |      ■
  |    ■
  |  ■
  |■                                ← 到期日，时间价值 = 0
  +------------------------------------------→ 时间
```

### 关键时间节点

| 时间段 | 衰减速度 | 对买/卖的影响 |
|-------|---------|-------------|
| 到期前 **7~3个月** | **缓慢** | 买方还能承受，卖方赚得慢 |
| 到期前 **3~1个月** | **加速** | 卖方开始舒服了 |
| 到期前 **<1个月** | **急剧加速** | 卖方赚得飞快，买方**非常不利** |

---

## 五、对交易策略的启示

### 如果你是买方（买期权）

> **时间是你的敌人**——每过一天，你的期权都在贬值

- 选 **到期日较远** 的期权（≥3个月）
- 这样可以减少时间损耗对你收益的侵蚀
- 你赌的是**方向**，不能被时间吃掉太多利润

### 如果你是卖方（卖期权）

> **时间是你的朋友**——每过一天，你都在赚钱

- 选 **到期日较近** 的期权（≤3个月，最好是1个月以内）
- 快速收割时间价值
- 甚至有些策略是**专门为卖方赚取时间损耗而设计的**

---

## 六、第八讲小结

| 概念 | 内容 |
|------|------|
| **时间衰减（Time Decay）** | 期权的时间价值随着到期日临近而逐渐归零 |
| **衰减速度** | 前期慢、后期快；到期前3个月开始加速，1个月内急剧加速 |
| **买方应对** | 选远期期权（≥3个月），减少时间损耗影响 |
| **卖方应对** | 选近期期权（≤3个月），快速收割时间价值 |
| **核心口诀** | **时间是买方的敌人，是卖方的朋友** |

---

# 第九讲：买方行权与卖方被行权

## 一、行权——买卖双方的权利与义务

回顾买方和卖方最根本的区别：

| 角色 | 权利 vs 义务 |
|------|-------------|
| **买方** | **有选择权**——可以选择行权，也可以选择不行权 |
| **卖方** | **有义务**——买方行权时，卖方必须配合 |

**理性的买方会如何决策？**

| 到期时的状态 | 买方会怎么做 | 原因 |
|-------------|------------|------|
| **ITM（价内）** | **行权** ✅ | 行权能获得收益 |
| **OTM（价外）** | **不行权** ❌ | 行权反而亏损 |
| **ATM（平价）** | **不行权** ❌ | 行权没有收益 |

---

## 二、专业术语

在券商的交易系统中，你会看到这两个词：

| 术语 | 英文 | 含义 |
|------|------|------|
| **行权** | **Exercise** | 买方行使手中的权利 |
| **被行权** | **Assignment** | 卖方被要求履行义务 |

---

## 三、美式期权 vs 欧式期权

根据**能否提前行权**，期权分为两种：

| 类型 | 特点 | 常见标的 |
|------|------|---------|
| **美式期权** | **可以**在到期前**任何时候**行权 | 绝大多数美股个股期权（如AAPL、SPY） |
| **欧式期权** | **只能**在**到期日当天**行权 | 少数指数期权（如标普500指数 SPX） |

> 我们平时交易的绝大多数期权都是**美式期权**。

---

## 四、一个常见的担心：卖方会不会被提前行权？

**担心：**
> "既然美式期权随时可以行权，那我做卖方岂不是要一直提心吊胆，怕被提前行权？"

**答案是：基本不用担心。**

### 为什么买方几乎不会提前行权？

因为期权不仅有**内在价值**，还有**时间价值**。

**举个例子：**
你有一张ITM的Call，现在股价153美元，行权价150美元。

| 选择 | 你拿到手的价值 |
|------|--------------|
| **提前行权** | 仅拿到内在价值 = **3美元**（150买入→153卖出） |
| **卖出期权** | 拿到期权总价 = 内在价值3美元 + **时间价值**1.55美元 ≈ **4.55美元** |

> 提前行权，你等于把时间价值白扔了。
> **把期权卖了比行权更划算！**

所以即使美式期权允许提前行权，理性的买方也会选择在市场上**卖出期权**来获利，而不是提前行权。因此卖方遇到提前被行权的概率**非常低**。

---

## 五、实际交易中要注意行权风险

虽然提前行权很少见，但**到期日**的行权是自动发生的，需要特别注意。

### 到期日自动处理规则

| 到期时的状态 | 券商处理方式 |
|-------------|------------|
| **OTM 或 ATM** | 自动**作废**，买方损失权利金，卖方赚到权利金 |
| **ITM** | 自动**行权**（哪怕只ITM了一分钱） |

### ITM自动行权带来的麻烦

如果到期时你的期权恰好是ITM，券商会自动帮你行权，这意味着：

**对买方：**
- 会被强制买入或卖出 **100股正股**
- 需要准备足够的资金
- 有些券商还会收取一笔**行权费用**

**对卖方：**
- 会被强制买入或卖出 **100股正股**
- 可能打乱你的持仓计划

### 最佳做法：在到期前处理掉

| 角色 | 到期前该怎么做 |
|------|--------------|
| **买方** | 如果期权是ITM，**提前卖出期权**赚取收益（包含时间价值） |
| **卖方** | 如果期权可能变成ITM，**提前平仓**（买回期权），承担一定亏损，避免被自动行权的麻烦 |

> 除非你交易期权就是**为了接正股或卖股票**，否则尽量不要让期权拖到到期自动行权。

## 六、第九讲小结

| 知识点 | 核心内容 |
|-------|---------|
| **权利与义务** | 买方有选择权，卖方有配合义务 |
| **Exercise / Assignment** | 行权（买方动作）/ 被行权（卖方被动） |
| **美式期权** | 可提前行权，但基本没人会提前做（因为卖期权更划算） |
| **欧式期权** | 只能到期行权，主要见于部分指数期权 |
| **到期自动处理** | OTM/ATM自动作废，ITM自动行权 |
| **最佳实践** | 到期前平仓处理，避免自动行权的麻烦 |

| **看跌期权** | Put Option | 给你按固定价格**卖出**资产的权利 |
| **正股/标的资产** | Underlying Asset | 期权合约对应的股票或ETF |
| **到期日** | Expiration Date | 期权合约的截止日 |
| **行权价** | Strike Price | 合约锁定的交易价格 |
| **权利金** | Premium | 买方付给卖方的费用（保费） |
| **隐含波动率** | Implied Volatility (IV) | 衡量期权贵不贵的指标 |
| **期权链** | Option Chain | 所有不同行权价的期权列表 |
| **买方** | Buyer of Option | 花钱买选择权的人，风险有限 |
| **卖方** | Seller of Option | 收钱承担义务的人，风险较大 |
| **价内期权** | In The Money (ITM) | 行权后能**赚钱**的期权 |
| **平价期权** | At The Money (ATM) | 行权价≈股价，行权无盈亏 |
| **价外期权** | Out of The Money (OTM) | 行权后**不赚钱**的期权 |
| **内在价值** | Intrinsic Value | 立即行权能获得的差价收益 |
| **时间价值** | Time Value | 期权价格中除去内在价值的部分 |
| **时间衰减** | Time Decay / Theta | 时间价值随到期日临近而逐渐归零的特性 |
| **行权** | Exercise | 买方行使期权权利的动作 |
| **被行权** | Assignment | 卖方被要求履行义务的动作 |
| **美式期权** | American Option | 可在到期前**任何时候**行权 |
| **欧式期权** | European Option | 只能**到期日当天**行权 |

## ITM / ATM / OTM 判断速查

| 类型 | Call | Put |
|------|------|-----|
| **ITM**（价内） | 行权价 **<** 股价 | 行权价 **>** 股价 |
| **ATM**（平价） | 行权价 **≈** 股价 | 行权价 **≈** 股价 |
| **OTM**（价外） | 行权价 **>** 股价 | 行权价 **<** 股价 |

## 价格变动速查

| 场景 | 股价上涨 | 股价下跌 |
|------|---------|---------|
| **Call 价格** | **上涨** ↑ | 下跌 ↓ |
| **Put 价格** | 下跌 ↓ | **上涨** ↑ |

## 期权价格构成速查

| 类型 | 内在价值 | 时间价值 |
|------|---------|---------|
| **ITM** | > 0（股价-行权价） | > 0 |
| **ATM** | ≈ 0 | ≈ 全部价格（通常最大） |
| **OTM** | = 0 | = 全部价格 |

## 买方 vs 卖方速查

| 对比 | 买方 | 卖方 |
|------|-----|------|
| 角色 | 花钱买选择权（服务的接受方） | 收钱承担义务（服务的提供方） |
| 最大亏损 | 权利金（**有限**） | 理论**无限** |
| 最大盈利 | 理论**无限** | 权利金（**有限**） |
| 希望股价 | 朝一个方向大幅移动 | 不动或反方向小幅移动 |
| 胜率 | **低**（赌对方向才能赚） | **高**（只要股价不极端变动就能赚） |
