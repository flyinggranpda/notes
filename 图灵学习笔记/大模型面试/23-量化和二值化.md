# 量化（Quantization）和二值化（Binarization）

## 1. 课程元信息

- **主题**：模型压缩的最后两种方式 — 量化（降低数值精度）与二值化（极致压缩）
- **前置知识**：模型压缩四种方式（剪枝/蒸馏/量化/二值化）、浮点数表示
- **核心目标**：理解量化和二值化的原理、精度-效率权衡，以及各自的适用场景

---

## 2. 核心概念图谱

| 术语 | 英文 | 通俗解释 |
|------|------|---------|
| 量化 | Quantization | 降低参数数值精度（FP32→INT8），减少存储和计算 |
| 二值化 | Binarization | 参数只用 +1/-1 表示，极致压缩 |
| FP32 | 32-bit Floating Point | 单精度浮点数，标准训练精度 |
| INT8 | 8-bit Integer | 8 位整数，量化最常用的精度等级 |
| STE | Straight-Through Estimator | 处理离散化梯度不能求导的技巧 |
| 校准 | Calibration | 量化后微调，恢复部分精度损失 |

---

## 3. 技术原理 / 流程拆解

### 3.1 数值精度谱系

```
FP32 (32-bit) ── 标准训练精度
  │
FP16 (16-bit) ── 半精度，训练常用
  │
INT8 (8-bit)  ── 量化最常用，性价比最高
  │
INT4 (4-bit)  ── 压缩更高但精度损失明显
  │
Binary (1-bit) ── 仅 +1/-1，极致压缩
```

### 3.2 量化（Quantization）

**核心思想**：将 FP32 的浮点数映射到 INT8 的整数范围，减少存储和计算。

```
FP32 数值: [0.0, 1.5, 3.14, -2.7, ...]
    ↓ 量化（除以缩放因子 + 取整）
INT8 数值: [0, 48, 100, -86, ...]
    ↓ 存储和计算（体积缩小 4 倍）
INT8 数值: [0, 48, 100, -86, ...]
    ↓ 反量化（乘以缩放因子）
FP32 近似值: [0.0, 1.49, 3.12, -2.68, ...]  ← 精度损失约 1%
```

**量化的优点：**
| 优点 | 说明 |
|------|------|
| 实现成本低 | 无需重新训练模型 |
| 硬件兼容性广 | 主流芯片都支持 INT8/INT4 |
| 推理速度提升 | 体积缩小 + 计算加速 |
| 精度损失小 | INT8 经校准后损失 < 1% |

**量化的缺点：**
| 缺点 | 说明 |
|------|------|
| INT4 以下损失显著 | NLP 任务 INT4 以下难以使用 |
| 对数值敏感任务不友好 | 精度损失可能影响结果正确性 |
| 极端值导致误差放大 | 需动态量化处理异常激活值 |

**适用场景**：快速部署、精度要求中等的场景（手机端图像识别、语音唤醒）

### 3.3 二值化（Binarization）

**核心思想**：参数只用 +1 或 -1 表示，体积压缩至 1/32。

```
FP32 参数:   [-1.2, 3.5, 0.0, 7.8, ...]
    ↓
二值化参数: [-1, +1, +1, +1, ...]    ← 每个参数只需 1 bit

压缩率: FP32 → Binary = 32 倍
计算效率: 提升 16~100 倍（专用硬件可达 100 倍+）
```

**二值化的挑战：**

```
离散化不可求导问题：
  二值化参数是离散值（+1/-1），无法直接求梯度
  ↓
STE 解决方案（Straight-Through Estimator）：
  前向传播：使用离散的二值化参数
  反向传播：绕过离散点，用连续的近似梯度更新
  ↓
  问题：梯度不准确 → 收敛不稳定 → 精度损失 10%~20%+
```

**适用场景**：
- 对算力和存储极度敏感的**边缘设备**（手表、摄像头、传感器）
- 任务简单且能接受精度损失（门禁人脸识别、文本分类）
- **不适用**：复杂任务（语义分割、精细人脸识别）

## 4. 四种模型压缩方式对比

| 对比 | 剪枝 | 蒸馏 | 量化 | 二值化 |
|------|------|------|------|--------|
| 压缩率 | 30%~70% | 40%~60% | 几倍~几百倍 | **极高**（32 倍+） |
| 精度损失 | 可控（可微调） | 极小 | <1% (INT8) | 10%~20%+ |
| 计算成本 | 高（需重训练） | 高（双模型） | **最低**（无需操作） | 高（STE 训练） |
| 硬件依赖 | 通用 | 通用 | 通用 | 需专用硬件加速 |
| 适用场景 | 精度优先 | 小模型替换大模型 | **快速部署** | 超低功耗边缘设备 |

---

## 5. 本节课思维导图

- 量化与二值化
  - 数值精度谱系：FP32 → FP16 → INT8 → INT4 → Binary
  - 量化（INT8 最常用）
    - 原理：浮点→整数映射
    - 优点：成本低、兼容广、损失 <1%
    - 场景：快速部署、精度中等
  - 二值化（极致压缩）
    - 原理：仅 +1/-1，32 倍压缩
    - 挑战：STE 梯度估计不准确
    - 精度损失 10%~20%
    - 场景：超低功耗边缘设备
  - 四种压缩方式对比
    - 剪枝：精度可控，成本高
    - 蒸馏：精度好，成本高
    - 量化：性价比最高
    - 二值化：极致压缩，精度牺牲大
