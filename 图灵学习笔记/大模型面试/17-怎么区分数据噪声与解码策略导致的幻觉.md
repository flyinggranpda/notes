# 怎么区分数据噪声与解码策略导致的幻觉

## 1. 课程元信息

- **主题**：大模型幻觉的根因定位 — 数据噪声 vs 解码策略
- **面试建议**：总分总结构（定义幻觉 → 分两类原因 → 合起来讲协同优化）
- **前置知识**：大模型解码策略（贪心搜索、Beam Search、Temperature）

---

## 2. 核心概念图谱

| 术语 | 英文 | 通俗解释 |
|------|------|---------|
| 幻觉 | Hallucination | 模型生成看似合理但事实错误的内容 |
| 数据噪声 | Data Noise | 训练数据中的错误/偏见导致模型学错了知识 |
| 解码策略 | Decoding Strategy | 生成文本时选择 token 的方式（贪心、采样、Beam Search） |
| 贪婪搜索 | Greedy Search | 每一步只选概率最高的 token，确定性输出 |
| Temperature | Temperature | 控制 softmax 分布平滑度的参数，越低越确定 |
| 相关无因果 | Correlation ≠ Causation | 两件事统计相关但无因果联系，如"冰棒销量↑→溺水↑" |

---

## 3. 技术原理 / 流程拆解

### 3.1 区分方法总览

核心方法：**控制变量法** — 固定解码策略，观察幻觉是否稳定出现。

```
将 Temperature 设为 0（等价于贪婪搜索）
对同一问题多次生成
    │
    ├── 每次结果都一样（稳定出现错误）
    │       ↓
    │   数据噪声导致（模型内化了错误知识）
    │
    └── 每次结果不一样（有时对有时错）
            ↓
        解码策略导致（模型知道正确答案，但解码时选错了）
```

### 3.2 四种区分维度

| 区分维度 | 数据噪声导致 | 解码策略导致 |
|---------|-------------|-------------|
| **多次生成结果** | 稳定出现相同错误 | 随机变化，时对时错 |
| **领域相关性** | 集中在特定领域/冷门知识 | 与领域无关，逻辑混乱 |
| **直接询问模型** | 直接问也答错 | 直接问能答对（但复杂任务中出错） |
| **调整解码参数** | 调参数无明显变化 | 降低 Temperature 后幻觉减少 |

### 3.3 相关无因果的经典陷阱

```
吃冰棒 🍦  → 统计相关 → 溺水事件 🏊
    ↑                        ↑
    └──────── 热 ☀️ ────────┘

相关：冰棒销量上升时，溺水事件也上升
因果：两者无直接因果关系，都是"热"导致的

大模型的问题：容易把"相关"误认为"因果"
```

## 4. 针对性应对策略

### 4.1 针对数据噪声

| 方法 | 说明 |
|------|------|
| **数据清洗** | 过滤训练数据中的错误事实和低质量文本 |
| **数据增强** | 针对冷门领域补充高质量数据 |
| **知识蒸馏 / RLHF** | 用高质量教师模型修正参数，弱化错误知识权重 |
| **RAG（外部检索）** | 让模型生成时参考外部权威知识库 |

### 4.2 针对解码策略

| 方法 | 说明 |
|------|------|
| **降低 Temperature** | 最直观有效，直接设为 0 判断问题根源 |
| **Beam Search 增大 beam size** | 提升全局最优性 |
| **约束解码** | 通过关键词约束限制生成偏离事实 |
| **分段生成 + 自校验** | 生成后每段自检逻辑一致性 |
| **外部校验融合** | 接入实时校验工具，高风险场景人工审核 |

---

## 5. 面试回答框架（总分总）

```
总：幻觉是大模型生成看似合理但事实错误的内容

分：
  1. 数据噪声导致 — 模型内化了训练数据中的错误
  2. 解码策略导致 — 模型知道正确答案，但生成时选错了路径
  3. 区分方法：Temperature=0 固定解码，多次生成观察是否稳定

合：实际场景中两者往往共同作用
  → 数据质量 + 解码策略协同优化
  → 高质量训练 + 合理解码参数 + 外部校验
```
