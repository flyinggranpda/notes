## 📌 一、项目概述

### 1.1 项目目标

做一个**智能文档检索助手**，用户上传 PDF/文档后，可以像聊天一样提问，系统自动检索文档内容并回答。

```
用户上传一份公司财报 PDF
         ↓
系统自动处理：分割 → 向量化 → 存储
         ↓
用户提问："这家公司的主要营收来源是什么？"
         ↓
系统检索文档 → LLM 回答 → 展示在网页上
```

### 1.2 技术栈

| 组件 | 技术选型 | 作用 |
|------|---------|------|
| **后端框架** | Flask / FastAPI | 提供 Web 接口 |
| **大模型** | OpenAI API / 本地模型 | 生成回答 |
| **向量数据库** | Chroma | 文档向量存储与检索 |
| **关系数据库** | MySQL | 存储原始文档和聊天记录 |
| **前端** | HTML + JavaScript（AI 生成） | 用户界面 |
| **PDF 解析** | pdfplumber + unstructured | 提取文档内容 |

## 🗄️ 三、数据库设计

### 3.1 MySQL 表结构

```sql
-- 原始文档表（存完整文档）
CREATE TABLE parent_documents (
    id INT PRIMARY KEY AUTO_INCREMENT,
    filename VARCHAR(255),        -- 文件名
    content TEXT,                  -- 文档完整内容
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 分割后的子文档表（存每个分块）
CREATE TABLE child_documents (
    id INT PRIMARY KEY AUTO_INCREMENT,
    parent_id INT,                 -- 关联原始文档
    content TEXT,                  -- 分块内容
    chunk_index INT,               -- 分块序号
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (parent_id) REFERENCES parent_documents(id)
);

-- 聊天记录表
CREATE TABLE chat_history (
    id INT PRIMARY KEY AUTO_INCREMENT,
    role VARCHAR(10),              -- 'user' / 'assistant'
    content TEXT,                  -- 消息内容
    doc_id INT,                    -- 关联的文档 ID
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

```
文档上传后，数据流程：
上传 PDF
    ↓
PDF 解析 → 提取完整文本 → 存到 parent_documents
    ↓
文本分割 → 切成 N 个 chunk → 存到 child_documents
    ↓
每个 chunk 向量化 → 存到 Chroma 向量库
```

### 3.2 为什么要存两份

```
MySQL（关系数据库）         Chroma（向量数据库）
├── 存完整原始文档          ├── 存向量 + 文档片段
├── 存聊天记录              ├── 用于相似度检索
├── 数据长期保存            ├── 检索速度快
└── 方便管理和查询          └── 缺点是数据不直观
```

两者互补：
- **向量库**用来快速检索
- **MySQL**用来保存原始数据和聊天记录

## 📄 四、文档处理流程

### 4.1 父子文档结构

```
父文档（parent_document）
  ├── 内容：整篇文档的全部文本
  ├── 作用：保证完整性，用于最终 LLM 上下文
  └── 不参与向量检索（太大了）
  
子文档（child_document）
  ├── 内容：分割后的每个片段
  ├── 作用：用于向量检索
  └── 每个子文档都对应一个向量
```

### 4.2 文档分割逻辑

```python
def split_document(full_text: str, chunk_size: int = 500, overlap: int = 50):
    """
    把文档分割成多个子文档（带重叠）
    
    参数:
        full_text: 原始文档全文
        chunk_size: 每个子文档的大小（字符数）
        overlap: 相邻子文档的重叠字符数
    
    返回:
        chunks: 分割后的片段列表
    """
    chunks = []
    start = 0
    
    while start < len(full_text):
        end = start + chunk_size
        chunk = full_text[start:end]
        chunks.append(chunk)
        start += chunk_size - overlap
    
    print(f"📄 文档已分割为 {len(chunks)} 个子文档")
    return chunks
```

### 4.3 PDF 表格处理

当文档中包含表格时，先用 PDF 解析工具识别出文本区域和表格区域，分别处理：

```python
def process_pdf_with_tables(pdf_path: str):
    """
    处理带表格的 PDF
    
    1. 用 pdfplumber 提取表格
    2. 用普通方式提取文本
    3. 把表格转换为结构化文字描述
    4. 合并所有内容
    """
    import pdfplumber
    
    pdf = pdfplumber.open(pdf_path)
    all_content = []
    
    for page in pdf.pages:
        # 提取表格
        tables = page.extract_tables()
        for table in tables:
            # 把表格转成文字描述
            table_text = table_to_text(table)
            all_content.append(table_text)
        
        # 提取文本（排除表格区域）
        text = page.extract_text()
        if text:
            all_content.append(text)
    
    return "\n".join(all_content)


def table_to_text(table):
    """把表格数据转换为自然语言描述"""
    if not table:
        return ""
    
    # 取表头
    header = table[0]
    rows = table[1:]
    
    lines = []
    for row in rows:
        pairs = [f"{h}: {v}" for h, v in zip(header, row)]
        lines.append("，".join(pairs))
    
    return "\n".join(lines)
```

## 🔧 五、RAG 核心实现

### 5.1 检索器实现

```python
class DocumentRetriever:
    """
    文档检索器：从向量库中检索与问题相关的子文档
    然后根据子文档找到对应的父文档作为上下文
    """
    
    def __init__(self, chroma_client, top_k=5):
        self.chroma = chroma_client
        self.top_k = top_k
    
    def retrieve(self, query: str):
        """
        1. 用 query 检索向量库 → 得到相关的子文档
        2. 根据子文档的 parent_id → 找到对应的父文档
        3. 返回父文档作为 LLM 的上下文
        """
        # Step 1: 向量检索
        results = self.chroma.similarity_search(query, k=self.top_k)
        
        # Step 2: 获取父文档 ID（去重）
        parent_ids = set()
        for r in results:
            parent_id = r.metadata.get("parent_id")
            if parent_id:
                parent_ids.add(parent_id)
        
        # Step 3: 从 MySQL 读取父文档完整内容
        full_docs = []
        for pid in parent_ids:
            parent_content = mysql_handler.get_parent_document(pid)
            full_docs.append(parent_content)
        
        return full_docs
```

### 5.2 带压缩的 RAG 链

```python
class RAGChain:
    """
    RAG 链：组合检索 + 压缩 + LLM 回答
    """
    
    def __init__(self, retriever, compressor, llm_client):
        self.retriever = retriever
        self.compressor = compressor   # 上下文压缩器
        self.llm = llm_client
    
    def query(self, user_question: str):
        # Step 1: 检索
        retrieved_docs = self.retriever.retrieve(user_question)
        
        # Step 2: 压缩上下文（可选）
        if self.compressor:
            compressed_docs = self.compressor.compress(user_question, retrieved_docs)
        else:
            compressed_docs = retrieved_docs
        
        # Step 3: 构建提示词
        context = "\n\n".join(compressed_docs)
        prompt = f"""基于以下文档内容回答问题。
如果文档中没有相关信息，请直接说不知道。

文档内容：
{context}

问题：{user_question}

回答："""
        
        # Step 4: 生成回答
        answer = self.llm.chat(prompt)
        
        return answer, retrieved_docs
```

## 🌐 六、Web 界面（Flask 版）

### 6.1 路由设计

```python
from flask import Flask, render_template, request, jsonify
import os

app = Flask(__name__)

# ============ 页面路由 ============

@app.route("/")
def index():
    """主页：展示聊天界面和文档管理"""
    documents = mysql_handler.get_all_documents()
    return render_template("index.html", documents=documents)


# ============ API 接口 ============

@app.route("/api/upload", methods=["POST"])
def upload_document():
    """上传文档 → 处理 → 入库"""
    file = request.files["file"]
    if not file:
        return jsonify({"error": "请选择文件"}), 400
    
    # 保存文件
    file_path = os.path.join("uploads", file.filename)
    file.save(file_path)
    
    # 处理文档（分割 + 向量化 + 存储）
    doc_id = process_document(file_path)
    
    return jsonify({
        "message": "文档上传成功",
        "doc_id": doc_id,
        "filename": file.filename
    })


@app.route("/api/chat", methods=["POST"])
def chat():
    """用户提问 → 检索 → 回答"""
    data = request.json
    question = data.get("question")
    doc_id = data.get("doc_id")  # 选择的文档
    
    # RAG 检索 + 回答
    answer, retrieved_docs = rag_chain.query(question)
    
    # 保存聊天记录
    mysql_handler.save_chat("user", question, doc_id)
    mysql_handler.save_chat("assistant", answer, doc_id)
    
    return jsonify({
        "answer": answer,
        "docs": retrieved_docs
    })


@app.route("/api/documents", methods=["GET"])
def list_documents():
    """获取所有已上传的文档列表"""
    documents = mysql_handler.get_all_documents()
    return jsonify({"documents": documents})


@app.route("/api/chat/history", methods=["GET"])
def get_chat_history():
    """获取聊天记录"""
    history = mysql_handler.get_chat_history()
    return jsonify({"history": history})


@app.route("/api/chat/clear", methods=["POST"])
def clear_chat():
    """清空聊天记录"""
    mysql_handler.clear_chat_history()
    return jsonify({"message": "聊天记录已清空"})
```
